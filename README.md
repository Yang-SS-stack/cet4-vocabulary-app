# 四级单词学习

捷语 · LinguaJet 是使用 React 和 Vite 构建的四级单词网页。目前包含启动页、导航、词书浏览、学习设置，以及可创建、学习和恢复的今日自评任务。

## 当前功能（2026-09-24 P-01 今日学习版）

- CET-4（4544 词）与 CET-4 高频词汇（2000 词），进入词书时加载数据。
- 排序采用纸面配色的“字母顺序 / 词频高低”双按钮，选中项保持高亮，支持键盘切换。普通词书默认字母 A–Z，高频词书默认词频降序；同频按字母排序，缺失词频排在最后。
- 搜索当前词书的英文拼写、中文释义或词性，忽略英文大小写和输入首尾空格。拼写与释义支持部分匹配；词性支持“名词 / 动词 / 及物动词”等中文名称和 `n.`、`vt.`、`adj` 等缩写，也兼容旧缩写 `a.`、`ad.`。“动词”包含各类动词，“及物动词”与“不及物动词”分别匹配；`art` 等查询仍可找到同名单词。
- 每页最多 **21 个单词**。搜索后只显示匹配词条，不补齐无关内容；搜索或排序改变时回到第一页。点击上一页或下一页后，先用 160ms 淡出，回到主页面顶部后用 240ms 淡入，最后将键盘焦点移到词书标题；过渡期间防止重复点击，系统启用减少动态效果时直接切换。
- 高频词卡正面直接显示已有词频；两本词书都会显示一条例句及中文翻译，例句完整呈现，不截断。点击词卡以 3D 动画翻到背面，查看完整释义、中文词性说明、例句和所有词组；高频词卡背面同时显示词频，较长详情可在卡片内滚动。
- 卡片底部居中显示“点击翻页”提示；点击卡片内容即可翻转。卡片悬停时与词书卡片一致，边框变金色并轻微右移；发音按钮仅文字变金色，不显示矩形底色。
- 点击背面内容或“返回单词正面”翻回；Tab 切换焦点，Enter / 空格打开，Escape 返回。系统启用减少动态效果时取消翻转动画。
- 正反面均提供单词“英音 / 美音”和“朗读例句”按钮，例句默认使用美音。按钮不触发翻转；连续点击重新朗读，切面、翻页或离开词表时停止当前词卡的朗读。

欢迎动画结束后，若学习计划尚未完成，网页会显示一个合并的五项设置弹窗：考试日期、学习词表、每日新词数量、每日复习数量和每日学习时长。“今日学习”进入或恢复当天自评任务；“今日复习”仍为未启用提示。选择“暂不开始”不会写入设置；刷新后会再次检查是否完整。所有已保存设置都只保存在当前浏览器和站点，刷新后仍会保留；清除站点数据会删除它们，当前没有账号或云同步。

“设置”页是首次设置完成后的修改入口。日期、词表、数量、时长和发音偏好都使用单一展开的滚动选择器：同一时刻只打开一项，切换时会保留上一项的草稿。数量范围为 1–100 词，时长范围为 5–240 分钟（每 5 分钟一档），发音默认英音且可改为美音。错题本每日学习数量也可在这里预先修改；错题本页面、学习入口和首次触发流程仍属于 Prompt 7。

学习建议会把研究原则、系统计划和用户设置分开。考试日期或词表改变后，系统会按该日期与词表的剩余词量自动个性化每日新词数和预计时长；新词数或复习数改变时也会更新预计时长，但用户仍可手动编辑最终计划时长。界面会显示未封顶的考试所需每日新词数；可编辑的系统建议最多为每天 100 词，超出时显示无法在考试前完成的提醒，且不会自动改写用户设置。预计时间按“每个新词 60 秒 + 每个复习词 20 秒”计算，并向上取整到 5 分钟；这些数字是产品按当前计划给出的个性化建议，不是研究规定的固定学习处方。若估算超过用户的学习时长，系统只提示用户可调整或仍然保存，不会擅自更改数量或时长。

普通 CET-4 数据没有词频字段，选择词频排序会给出提示并按字母排列，普通 CET-4 卡片不显示词频区域。高频词书使用已有词频数值；本版不补充或重新核验词频来源。释义或词组缺失时显示提示。

## 词表数据生成

`public/data/cet4.json` 和 `public/data/cet4-high-frequency.json` 中的旧 JSON 词表仍是构建源文件。词表内容变动后运行：

```powershell
npm run build:wordbooks
```

该命令会重新生成 `public/data/word-books` 下的运行时资源。网页不会一次请求完整旧 JSON，而是先请求词书清单文件（manifest）、搜索索引，再按当前页面请求需要的单词详情分片。

为原词库缺少例句的 95 个词补写了简短例句和中文翻译，统一标注“补充例句”；同一份补充数据也覆盖高频词书的 21 处缺失。两本词书每个词均有可朗读例句，原有例句保持不变。补充句不是来源词库的真题例句。原词条 `reservior` 的补充句使用规范拼写 `reservoir` 并显示提示；原始词条、词性和释义未作全面校订。

词卡优先播放预先生成的本地音频：单词提供英音 Sonia 和美音 Jenny，例句使用美音 Jenny，语速比试听原文默认值慢 10%。播放不依赖系统安装的英语声音，也不自动播放；浏览器不支持本地音频时才退回浏览器语音，本地音频播放失败会明确提示。试听页保留在 `/audio-preview/2026-09-08/index.html`。批量音频的生成脚本和声音配置见 `scripts/generate-audio.py` 与 `src/data/audioManifest.json`。

P-01 已实现今日新词自评闭环及自评“不认识”达到 5 次后的错误证据入库。实际复习任务、间隔排程、错误证据库页面与学习流程仍未实现。首次设置仅保存配置，点击“今日学习”才创建任务。词表浏览保持原有行为。

## 本地打开

在项目目录运行：

```powershell
npm run dev
```

然后打开命令行显示的本机地址。

首次使用先运行 `npm ci` 安装依赖。独立工作区预览可运行：

```powershell
npm run dev -- --host 127.0.0.1 --port 5187 --strictPort
```

打开 [本机预览](http://127.0.0.1:5187/) 。这个地址只用于本机预览。

## 手动验收

1. 进入“词表”并打开 CET-4，确认每页最多 21 张词卡；滚动到底部点击下一页或上一页，确认新页面从主页面顶部开始。
2. 输入 `APP` 或 `苹果`，确认仅保留拼写或释义匹配的词条；输入不存在的内容，确认空结果提示及“清空搜索”有效。
3. 输入 `名词`、`vt.`、`不及物动词` 检查相关词性；切换到高频词书，正面应直接显示词频与例句。普通词书不应出现词频区域。搜索 `approximately`，应看到“补充例句”及翻译。
4. 点击词卡，检查正反面文字没有镜像或叠在一起；将鼠标停在详情区域内，用滚轮滚动到最后一个词组，确认主页面不会随之滚动，返回与发音按钮始终可用。
5. 只用键盘操作：Tab 选中词卡，Enter / 空格打开，Escape 或返回按钮翻回；隐藏一面的控件不应获得焦点。
6. 分别点击“英音 / 美音”和“朗读例句”，试听本地单词及整句且不翻卡；连续点击、切面、翻页和返回词书时检查播放取消行为。
7. 缩窄浏览器至手机宽度，检查搜索框、排序、词卡和分页不横向溢出；启用减少动态效果后，卡片应直接切面。

## P-01 今日学习与验收

点击“今日学习”先恢复当天任务；没有任务时，按词书资源中的默认顺序（全量字母顺序、高频词频顺序）选择该词书未完成词，不超过每日新词数。词集、日期、设置快照、自评方式和规则版本固定；同日换词书或数量不重抽。

先回想词义，选择“认识／模糊／不认识”后显示完整释义、例句、词组和发音。认识加 1、达到 3 完成；模糊减 1 最低 0；不认识清零并累计独立的自评错误证据。点击“下一词”按任务顺序循环未完成词。最后一次反馈后仍保留详情，点击下一词才展示完成页。上述完成规则只属于自评方式。

浏览器写入经过同站点互斥锁，反馈与详情状态一次保存。退出、刷新或切换页面后，再点“今日学习”恢复当前位置与题面／详情。设备本地 00:00 后不能继续写入昨日任务；历史保留，遗留词重新从当日 0 次认识开始。加载／保存失败可重试，冲突可重新读取已保存进度，不自动覆盖。

旧版 v1 数据校验后在内存无损转换为 v2，首次成功写入才落盘；未知或损坏数据仍保留并进入原有恢复页。详细接口与兼容边界见 [学习数据文档](docs/learning-data.md)。

生产预览（本机专用）：

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 5191 --strictPort
```

打开 [P-01 本机预览](http://127.0.0.1:5191/)。必须使用同一浏览器、主机名和端口恢复本地记录；不同端口的预览与线上站点互相隔离。

人工验收：

1. 在设置中设每日新词为 1–2 个，进入今日学习，检查数量和默认顺序；答案应隐藏。
2. 点认识后检查详情、例句和发音；在详情页刷新、重进，再点下一词，应恢复并继续。
3. 退出并修改每日数量和词书，再进入当天任务，检查固定词集与原词书保持不变。
4. 用一词任务检查认识加 1、模糊减 1、不认识清零；三次认识后，下一词进入完成页。
5. 对同词完成五轮“不认识 → 下一词”，详情应提示已进入错误证据库；双击反馈不重复计数。
6. 两标签同时进入任务；一个提交，另一个提交应提示冲突，重新读取后显示已保存详情。
7. 本地跨天、加载失败、保存失败、旧数据迁移在自动化测试中有时钟／存储注入验证；真实浏览器可用开发者工具断网验证首次词书加载失败重试。不要为了验收清除真实站点记录。

限制：仅本地存储，无云同步；写入要求浏览器支持 Web Locks，使用本机地址或 HTTPS。历史 v1 没有逐次事件，迁移不会伪造旧反馈事件。没有实际复习排程、其他题型或 Agent 接入。旧版本页面不理解 v2，应关闭旧版本标签后使用新版，避免来回切换版本写入。音频清单仍按需加载，保留现有大资源构建提醒。
