# 四级单词学习

捷语 · LinguaJet 是使用 React 和 Vite 构建的四级单词网页。目前包含启动页、导航、词书列表和词表浏览。

## 当前功能（2026-09-08 词表预览版）

- CET-4（4544 词）与 CET-4 高频词汇（2000 词），进入词书时加载数据。
- 排序采用纸面配色的“字母顺序 / 词频高低”双按钮，选中项保持高亮，支持键盘切换。普通词书默认字母 A–Z，高频词书默认词频降序；同频按字母排序，缺失词频排在最后。
- 搜索当前词书的英文拼写、中文释义或词性，忽略英文大小写和输入首尾空格。拼写与释义支持部分匹配；词性支持“名词 / 动词 / 及物动词”等中文名称和 `n.`、`vt.`、`adj` 等缩写，也兼容旧缩写 `a.`、`ad.`。“动词”包含各类动词，“及物动词”与“不及物动词”分别匹配；`art` 等查询仍可找到同名单词。
- 每页最多 **21 个单词**。搜索后只显示匹配词条，不补齐无关内容；搜索或排序改变时回到第一页。点击上一页或下一页后，先用 160ms 淡出，回到主页面顶部后用 240ms 淡入，最后将键盘焦点移到词书标题；过渡期间防止重复点击，系统启用减少动态效果时直接切换。
- 高频词卡正面直接显示已有词频；两本词书都会显示一条例句及中文翻译，例句完整呈现，不截断。点击词卡以 3D 动画翻到背面，查看完整释义、中文词性说明、例句和所有词组；高频词卡背面同时显示词频，较长详情可在卡片内滚动。
- 点击背面内容或“返回单词正面”翻回；Tab 切换焦点，Enter / 空格打开，Escape 返回。系统启用减少动态效果时取消翻转动画。
- 正反面均提供单词“英音 / 美音”和“朗读例句”按钮，例句默认使用美音。按钮不触发翻转；连续点击重新朗读，切面、翻页或离开词表时停止当前词卡的朗读。

普通 CET-4 数据没有词频字段，选择词频排序会给出提示并按字母排列，普通 CET-4 卡片不显示词频区域。高频词书使用已有词频数值；本版不补充或重新核验词频来源。释义或词组缺失时显示提示。

为原词库缺少例句的 95 个词补写了简短例句和中文翻译，统一标注“补充例句”；同一份补充数据也覆盖高频词书的 21 处缺失。两本词书每个词均有可朗读例句，原有例句保持不变。补充句不是来源词库的真题例句。原词条 `reservior` 的补充句使用规范拼写 `reservoir` 并显示提示；原始词条、词性和释义未作全面校订。

词卡优先播放预先生成的本地音频：单词提供英音 Sonia 和美音 Jenny，例句使用美音 Jenny，语速比试听原文默认值慢 10%。播放不依赖系统安装的英语声音，也不自动播放；浏览器不支持本地音频时才退回浏览器语音，本地音频播放失败会明确提示。试听页保留在 `/audio-preview/2026-09-08/index.html`。批量音频的生成脚本和声音配置见 `scripts/generate-audio.py` 与 `src/data/audioManifest.json`。

“认识 / 模糊 / 不认识”、本地学习进度及复习安排尚未实现，留到“今日学习”阶段。当前搜索、排序及翻转状态仅在本次浏览有效。

## 本地打开

在项目目录运行：

```powershell
npm run dev
```

然后打开命令行显示的本机地址。

首次使用先运行 `npm ci` 安装依赖。独立工作区预览可运行：

```powershell
npm run dev -- --host 127.0.0.1 --port 5187 --strictPort
```

打开 [本机预览](http://127.0.0.1:5187/) 。这个地址只用于本机预览。

## 检查项目

```powershell
npm test
npm run lint
npm run build
```

- `npm test`：检查启动页、导航、数据加载、搜索排序、分页、词卡翻转及语音边界行为。
- `npm run lint`：检查代码写法。
- `npm run build`：检查网页能否打包为可运行文件。

本版完整验证使用 `npm test -- --maxWorkers=2`，覆盖搜索排序、中文词性、卡片正反面、英美语音选择与取消、补充例句覆盖，以及既有页面功能；另运行代码规范检查和生产构建。降低测试并行数量以避免原有粒子动画测试偶发超时，不修改超时或跳过测试。

浏览器已核对桌面与 390px 窄屏、中英文搜索、实际词频排序、长详情滚动、键盘焦点、减少动态效果和发音不翻卡；本地试听音频已生成并单独核对文件时长与采样率。

## 手动验收

1. 进入“词表”并打开 CET-4，确认每页最多 21 张词卡；滚动到底部点击下一页或上一页，确认新页面从主页面顶部开始。
2. 输入 `APP` 或 `苹果`，确认仅保留拼写或释义匹配的词条；输入不存在的内容，确认空结果提示及“清空搜索”有效。
3. 输入 `名词`、`vt.`、`不及物动词` 检查相关词性；切换到高频词书，正面应直接显示词频与例句。普通词书不应出现词频区域。搜索 `approximately`，应看到“补充例句”及翻译。
4. 点击词卡，检查正反面文字没有镜像或叠在一起；将鼠标停在详情区域内，用滚轮滚动到最后一个词组，确认主页面不会随之滚动，返回与发音按钮始终可用。
5. 只用键盘操作：Tab 选中词卡，Enter / 空格打开，Escape 或返回按钮翻回；隐藏一面的控件不应获得焦点。
6. 分别点击“英音 / 美音”和“朗读例句”，试听本地单词及整句且不翻卡；连续点击、切面、翻页和返回词书时检查播放取消行为。
7. 缩窄浏览器至手机宽度，检查搜索框、排序、词卡和分页不横向溢出；启用减少动态效果后，卡片应直接切面。
