# 四级单词学习

捷语 · LinguaJet 是使用 React 和 Vite 构建的四级单词网页。目前包含启动页、导航、词书浏览、学习设置，以及可创建、渐进学习和恢复的今日任务。

## 当前功能（2026-09-29 P-01 渐进学习与额外学习版）

- CET-4（4544 词）与 CET-4 高频词汇（2000 词），进入词书时加载数据。
- 排序采用纸面配色的“字母顺序 / 词频高低”双按钮，选中项保持高亮，支持键盘切换。普通词书默认字母 A–Z，高频词书默认词频降序；同频按字母排序，缺失词频排在最后。
- 搜索当前词书的英文拼写、中文释义或词性，忽略英文大小写和输入首尾空格。拼写与释义支持部分匹配；词性支持“名词 / 动词 / 及物动词”等中文名称和 `n.`、`vt.`、`adj` 等缩写，也兼容旧缩写 `a.`、`ad.`。“动词”包含各类动词，“及物动词”与“不及物动词”分别匹配；`art` 等查询仍可找到同名单词。
- 每页最多 **21 个单词**。搜索后只显示匹配词条，不补齐无关内容；搜索或排序改变时回到第一页。点击上一页或下一页后，先用 160ms 淡出，回到主页面顶部后用 240ms 淡入，最后将键盘焦点移到词书标题；过渡期间防止重复点击，系统启用减少动态效果时直接切换。
- 高频词卡正面直接显示已有词频；两本词书都会显示一条例句及中文翻译，例句完整呈现，不截断。点击词卡以 3D 动画翻到背面，查看完整释义、中文词性说明、例句和所有词组；高频词卡背面同时显示词频，较长详情可在卡片内滚动。
- 卡片底部居中显示“点击翻页”提示；点击卡片内容即可翻转。卡片悬停时与词书卡片一致，边框变金色并轻微右移；发音按钮仅文字变金色，不显示矩形底色。
- 点击背面内容或“返回单词正面”翻回；Tab 切换焦点，Enter / 空格打开，Escape 返回。系统启用减少动态效果时取消翻转动画。
- 正反面均提供单词“英音 / 美音”和“朗读例句”按钮，例句默认使用美音。按钮不触发翻转；连续点击重新朗读，切面、翻页或离开词表时停止当前词卡的朗读。

欢迎动画结束后，若学习计划尚未完成，网页会显示一个合并的五项设置弹窗：考试日期、学习词表、每日新词数量、每日复习数量和每日学习时长。“今日学习”进入或恢复当天学习任务；“今日复习”仍为未启用提示。选择“暂不开始”不会写入设置；刷新后会再次检查是否完整。所有已保存设置都只保存在当前浏览器和站点，刷新后仍会保留；清除站点数据会删除它们，当前没有账号或云同步。

“设置”页是首次设置完成后的修改入口。日期、词表、数量、时长和发音偏好都使用单一展开的滚动选择器：同一时刻只打开一项，切换时会保留上一项的草稿。数量范围为 1–100 词，时长范围为 5–240 分钟（每 5 分钟一档），发音默认英音且可改为美音。错题本每日学习数量也可在这里预先修改；错题本页面、学习入口和首次触发流程仍属于 Prompt 7。

学习建议会把研究原则、系统计划和用户设置分开。考试日期或词表改变后，系统会按该日期与词表的剩余词量自动个性化每日新词数和预计时长；新词数或复习数改变时也会更新预计时长，但用户仍可手动编辑最终计划时长。界面会显示未封顶的考试所需每日新词数；可编辑的系统建议最多为每天 100 词，超出时显示无法在考试前完成的提醒，且不会自动改写用户设置。预计时间按“每个新词 60 秒 + 每个复习词 20 秒”计算，并向上取整到 5 分钟；这些数字是产品按当前计划给出的个性化建议，不是研究规定的固定学习处方。若估算超过用户的学习时长，系统只提示用户可调整或仍然保存，不会擅自更改数量或时长。

普通 CET-4 数据没有词频字段，选择词频排序会给出提示并按字母排列，普通 CET-4 卡片不显示词频区域。高频词书使用已有词频数值；本版不补充或重新核验词频来源。释义或词组缺失时显示提示。

## 词表数据生成

`public/data/cet4.json` 和 `public/data/cet4-high-frequency.json` 中的旧 JSON 词表仍是构建源文件。词表内容变动后运行：

```powershell
npm run build:wordbooks
```

该命令会重新生成 `public/data/word-books` 下的运行时资源。网页不会一次请求完整旧 JSON，而是先请求词书清单文件（manifest）、搜索索引，再按当前页面请求需要的单词详情分片。

为原词库缺少例句的 95 个词补写了简短例句和中文翻译，统一标注“补充例句”；同一份补充数据也覆盖高频词书的 21 处缺失。两本词书每个词均有可朗读例句，原有例句保持不变。补充句不是来源词库的真题例句。原词条 `reservior` 的补充句使用规范拼写 `reservoir` 并显示提示；原始词条、词性和释义未作全面校订。

词卡优先播放预先生成的本地音频：单词提供英音 Sonia 和美音 Jenny，例句使用美音 Jenny，语速比试听原文默认值慢 10%。词书浏览只在点击时播放。今日学习会按下面的阶段自动朗读，优先使用同一份本地音频；清单加载成功或明确失败后才开始本轮自动播放，题目与保存操作不等待声音。缺少音频或浏览器不支持本地音频时退回浏览器语音，且只选择指定口音；本地音频播放失败会明确提示。试听页保留在 `/audio-preview/2026-09-08/index.html`。批量音频的生成脚本和声音配置见 `scripts/generate-audio.py` 与 `src/data/audioManifest.json`。

P-01 已实现今日新词自评闭环及自评“不认识”达到 5 次后的错误证据入库。实际复习任务、间隔排程、错误证据库页面与学习流程仍未实现。首次设置仅保存配置，点击“今日学习”才创建任务。词表浏览保持原有行为。

## 本地打开

在项目目录运行：

```powershell
npm run dev
```

然后打开命令行显示的本机地址。

首次使用先运行 `npm ci` 安装依赖。独立工作区预览可运行：

```powershell
npm run dev -- --host 127.0.0.1 --port 5187 --strictPort
```

打开 [本机预览](http://127.0.0.1:5187/) 。这个地址只用于本机预览。

## 手动验收

1. 进入“词表”并打开 CET-4，确认每页最多 21 张词卡；滚动到底部点击下一页或上一页，确认新页面从主页面顶部开始。
2. 输入 `APP` 或 `苹果`，确认仅保留拼写或释义匹配的词条；输入不存在的内容，确认空结果提示及“清空搜索”有效。
3. 输入 `名词`、`vt.`、`不及物动词` 检查相关词性；切换到高频词书，正面应直接显示词频与例句。普通词书不应出现词频区域。搜索 `approximately`，应看到“补充例句”及翻译。
4. 点击词卡，检查正反面文字没有镜像或叠在一起；将鼠标停在详情区域内，用滚轮滚动到最后一个词组，确认主页面不会随之滚动，返回与发音按钮始终可用。
5. 只用键盘操作：Tab 选中词卡，Enter / 空格打开，Escape 或返回按钮翻回；隐藏一面的控件不应获得焦点。
6. 分别点击“英音 / 美音”和“朗读例句”，试听本地单词及整句且不翻卡；连续点击、切面、翻页和返回词书时检查播放取消行为。
7. 缩窄浏览器至手机宽度，检查搜索框、排序、词卡和分页不横向溢出；启用减少动态效果后，卡片应直接切面。

## P-01 今日学习与验收（2026-09-27）

点击“今日学习”先恢复当天任务；没有任务时按词书默认顺序选取未完成词，不超过每日新词数。当天的词集、日期、设置和学习方式固定，修改设置不会重抽。

新任务采用渐进回忆方式（guided-recall v1）：

- 认识次数 0：单词、音标、朗读和四个中文释义选项。首次选对加 1；选错或看答案保持 0。选后在原处显示标记及对应英文：选错先标红并朗读错误选项单词，随后朗读正确单词时标绿；选对直接朗读正确单词。点击“继续”进入完整详情；“看答案”直接进入详情。
- 认识次数 1：题面只显示单词和英文例句，隐藏中文翻译。
- 认识次数 2：题面只显示单词。
- 后两轮使用认识／模糊／不认识自评；认识加 1，达到 3 完成；模糊减 1 最低 0；不认识清零。回到 0 时下次重新四选一。
- 每次反馈后仍可查看完整释义、双语例句、词组和发音，点击“下一词”继续。最后一个词完成后仍保留详情。

选择题答错保存为独立的 guided-choice 事件，不计入自评“不认识”阈值；自评不认识累计达到 5 次仍按原规则标记错误证据。选项来自同一本词书，排除重复释义和相同释义片段；不使用模型生成。首版筛选不等于人工语义审校，近义干扰项质量仍需产品验收。

学习与复习入口隐藏主导航和页面大标题，仅保留返回主界面及任务信息。复习当前是未启用页面。单词卡片适应窗口高度，详情在宽屏分栏，超长正文在卡片内部滚动；底部按钮独立保留。选择反馈固定单词和选项位置，红／绿色背景、边框、文字以 350ms 渐变，对应英文同步淡入，进入详情仅下方内容淡出淡入；点击“下一词”才整体以 160ms 淡出、240ms 淡入切换，同一词进入下一轮也算下一词操作。减少动态效果时直接切换。键盘焦点在选择后移到“继续”，详情切换后移到可滚动正文，下一词切换后移到单词标题。

自动朗读顺序：首轮题面仅读单词；第二轮题面读单词再读英文例句；第三轮题面仅读单词；完整详情读单词再读英文例句，不朗读中文。单词使用当天任务固定的英音／美音设置，既有例句音频始终使用美音 Jenny。自动播放、重播本轮以及详情中的手动发音共享一个播放队列；新的播放会停止旧队列，下一词、确认退出、日期失效或保存错误也会停止播放，迟到结束事件不会启动旧例句。失败会显示提示，仍可继续学习或点击“重播朗读”；挂起的声音有超时停止，不会永久隐藏正确答案。

完整详情中，刚刚自评“认识”或首轮选对时可点一次“记错了”：认识次数减 1（最低 0），按模糊保存，留在详情。3→2 同时撤销本词完成和总已学习统计；不增加不认识次数或错误证据。原反馈保留，并追加独立更正事件，刷新也不能再扣。

返回主界面时，未完成任务显示“当前任务剩余 N 词”（额外学习显示“本组剩余 N 词”）。取消保持进度并恢复返回按钮焦点；确认立即停止朗读，学习页以 240ms 淡出后主页以 240ms 淡入，退出期间不能重复操作。完成或无任务直接返回，不显示多余确认；减少动态效果时直接切换。

反馈、更正、所选选项、选项结果／详情状态、下一词均可靠保存。退出或刷新后重进当天任务可恢复。写入使用同站点 Web Locks 和版本校验；重复提交、跨天和冲突拒绝覆盖，失败可重试。设备本地 00:00 为日期边界。

完成固定今日任务后，再进入“今日学习”会提示是否继续学习更多单词。确认后从同一本词书按默认顺序学习未完成新词，以每组最多 10 词自动接续，不受每日词数上限限制；原任务保持不变。额外过程的当前词、选择反馈和详情可退出恢复，完成计入词书总已学习数量且每词只计一次，全书完成会明确提示。

v1/v2/v3/v4 数据验证后在内存迁移为 v5，首次成功写入才落盘。旧任务保留原自评方式、选择反馈及进度，不静默改规则；新任务才使用渐进方式。上述三轮题面与朗读顺序适用于渐进学习；旧版自评任务题面仍只读单词，完整详情读单词和英文例句。未知或损坏数据保留并进入原有恢复页。详见 [学习数据文档](docs/learning-data.md)。

人工验收：

1. 在新预览设置每日 1 词。进入今日学习，检查四个选项和“看答案”，确认导航消失。
2. 选错时先听错误单词、看到红色，再听正确单词、看到绿色；标题和四个选项不移动。刷新重进恢复同一选择反馈与朗读阶段，认识仍为 0；“继续”只切换标题下方详情，“下一词”再次四选一。
3. 首次选对后，经过详情与下一词，检查只有单词和英文例句；再点认识、下一词，检查只剩单词；第三次认识后完成。
4. 在选项结果和详情分别刷新，检查不重复加次数；返回主界面再进入应恢复同一状态。
5. 缩小窗口或放大文字：长正文可以内部滚动，底部“继续／下一词”可见；详情仅下方淡出淡入，下一词整体过渡，开启系统减少动态效果后取消动画。键盘操作应能继续并进入正文。
6. 自评模糊应回退一层，不认识应回到首轮；五次自评不认识才进入错误证据库，首轮选错不应计入。
7. 同时打开两个标签，一个提交后另一个提交应提示冲突；重新读取后恢复已保存状态。
8. 试听每一轮、详情、错误选项和正确选项的顺序；朗读中手动重播、下一词或确认退出，声音应立即停止旧段，不能重叠。拦截音频后应有提示，重播或继续学习仍可用。
9. 完成今日任务后再次进入，取消继续提示不写入；确认后检查额外新词按顺序接续，退出恢复反馈或详情，词书总已学习数量增加且原今日任务不扩充。

10. 在首轮选对的完整详情和自评认识的详情点“记错了”，检查减一次、停留详情、刷新后不可重扣；第三次认识后更正应撤销完成。选错、看答案、模糊及不认识的详情无更正按钮。
11. 有剩余词时返回，分别取消、按 Escape 和确认；核对剩余数量、焦点恢复、停止声音和退出／主页淡入。额外学习确认框只统计本组，完成状态不弹确认。

自动化验证：`npm test -- --maxWorkers=2`、`npm run lint`、`npm run build`。日期、失败写入与迁移使用可注入时钟和存储测试。真实窗口布局与动效仍需浏览器人工验收。

本轮朗读与过渡通过组件交互和可控 Audio／浏览器语音事件验证；浏览器自动化连接暂时失败，未声称本轮真实设备发声、截图、窄屏布局或原生键盘行为已验证。

限制：本地保存，无账号／云同步；暂无实际复习排程或 Agent 接入。旧版页面不理解 v5，应关闭旧版本标签后使用新版。音频清单仍有原有大资源构建提醒。
