# 四级单词学习

捷语 · LinguaJet 是使用 React 和 Vite 构建的四级单词网页。目前包含启动页、导航、词书列表和词表浏览。

## 当前功能（2026-09-07 词表预览版）

- CET-4（4544 词）与 CET-4 高频词汇（2000 词），进入词书时加载数据。
- 字母 A–Z / 词频降序排列。普通词书默认字母排序，高频词书默认词频排序；同频按字母排序，缺失词频排在最后。
- 搜索当前词书的英文拼写或中文释义，支持部分匹配，忽略英文大小写和输入首尾空格。
- 每页最多 **21 个单词**。搜索后只显示匹配词条，不补齐无关内容；搜索或排序改变时回到第一页。点击上一页或下一页后自动回到主页面顶部，键盘焦点移到词书标题。
- 点击词卡以 3D 动画翻到背面，查看完整释义、例句及翻译、所有词组和已有词频；较长详情可在卡片内滚动。
- 点击背面内容或“返回单词正面”翻回；Tab 切换焦点，Enter / 空格打开，Escape 返回。系统启用减少动态效果时取消翻转动画。
- 背面“发音”调用浏览器英语语音，连续点击重新朗读；翻回、翻页或离开词表时停止当前词卡的朗读。

当前普通 CET-4 数据没有词频字段，选择词频排序会给出提示并按字母排列。高频词书使用已有词频数值；本版不补充或重新核验词频来源，不将缺失数据当成零。释义、例句或词组缺失时显示提示。

发音依赖浏览器和系统安装的英语语音，部分声音可能需要联网；不支持或发音失败时会提示，不自动播放。

“认识 / 模糊 / 不认识”、本地学习进度及复习安排尚未实现，留到“今日学习”阶段。当前搜索、排序及翻转状态仅在本次浏览有效。

## 本地打开

在项目目录运行：

```powershell
npm run dev
```

然后打开命令行显示的本机地址。

首次使用先运行 `npm ci` 安装依赖。独立工作区预览可运行：

```powershell
npm run dev -- --host 127.0.0.1 --port 5187 --strictPort
```

打开 [本机预览](http://127.0.0.1:5187/) 。这个地址只用于本机预览。

## 检查项目

```powershell
npm test
npm run lint
npm run build
```

- `npm test`：检查启动页、导航、数据加载、搜索排序、分页、词卡翻转及语音边界行为。
- `npm run lint`：检查代码写法。
- `npm run build`：检查网页能否打包为可运行文件。

本版验证：50 项完整测试通过、代码规范检查通过、生产构建通过。首次并行测试中原有粒子动画测试曾超时，单独运行通过；完整复验使用 `npm test -- --maxWorkers=2` 降低并行数量，没有修改测试超时或跳过测试。

浏览器已核对桌面与 390px 窄屏、中英文搜索、实际词频排序、长详情滚动、键盘焦点、减少动态效果和发音不翻卡。实际声音效果仍取决于本机语音服务，可按下面步骤试听。

## 手动验收

1. 进入“词表”并打开 CET-4，确认每页最多 21 张词卡；滚动到底部点击下一页或上一页，确认新页面从主页面顶部开始。
2. 输入 `APP` 或 `苹果`，确认仅保留拼写或释义匹配的词条；输入不存在的内容，确认空结果提示及“清空搜索”有效。
3. 切换到高频词书，在两种排序间切换；翻到背面核对词频。普通词书缺失词频时应显示“暂无词频数据”。
4. 点击词卡，检查正反面文字没有镜像或叠在一起；将鼠标停在详情区域内，用滚轮滚动到最后一个词组，确认主页面不会随之滚动，返回与发音按钮始终可用。
5. 只用键盘操作：Tab 选中词卡，Enter / 空格打开，Escape 或返回按钮翻回；隐藏一面的控件不应获得焦点。
6. 点击“发音”，确认只朗读该单词且不会翻回；连续点击、翻页和返回词书时检查朗读取消行为。
7. 缩窄浏览器至手机宽度，检查搜索框、排序、词卡和分页不横向溢出；启用减少动态效果后，卡片应直接切面。
