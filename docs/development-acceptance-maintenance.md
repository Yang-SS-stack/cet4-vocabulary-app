## 页面怎么使用

从“设置”底部进入“开发验收与维护”。如果设置有修改，确认框默认留在设置，Escape 也会留下；选择“放弃修改并进入”才丢弃当前草稿，不会自动保存或读取别处设置。保存中、滚轮尚未稳定时暂时不能进入。

用户已批准“今日学习”和“统计”同步视觉重做，制作及自动核验完成，等待逐步人工验收。今日学习以三环查看固定新词、本轮额外学习、固定复习，原学习建议默认折叠。统计用独立按钮查看各词书的全部/近7天/今日记录，继续区分唯一词与词次、进度与实际反馈、原反馈与有效更正、缺失与零值；筛选不修改学习设置。最新制作与验收状态见 [两页增量验收记录](today-statistics-visual-acceptance.md)。

维护页有三个视图：

| 视图 | 用途 |
| --- | --- |
| 连接与检查 | 先选择连接、当前摘要或固定非法示例，再主动执行；一次展示一个项目 |
| 记录依据 | 本地查看已有任务、事件、异常及原始对账字段，每页50条 |
| 检查记录 | 当前标签页最近20次操作的安全终态；选择一条预览，再复制 |

已有连接时再次进入默认选择当前摘要，正在进行的操作优先显示对应项目。操作等待期间不能换检查项目，可取消或断开；切到学习页不会重发请求。连接是临时会话状态，不证明服务此刻仍在线。顶部独立显示当前摘要尚未检查、检查中、通过、失败、依据变化、取消或过期。

检查历史属于当时技术结果，不能当成人工验收通过。学习记录、日期或会话变化会使旧真实摘要结果失效。记录只在当前标签页内存中，刷新/关闭后消失；清空只清历史，不清连接、当前结论或学习记录。新连接会丢弃旧会话的当前错误提示，失效历史仍保留。

报告只包含固定检查字段和公共版本信息。逐词明细、学习计数、考试日期、原始快照、依据指纹、连接码和会话令牌不会进入报告；未知信息显示“未取得”。复制失败时下方文本仍可选中手动复制。没有历史时可以查看明确标记的演示报告，它没有执行请求，也不插入真实历史。
