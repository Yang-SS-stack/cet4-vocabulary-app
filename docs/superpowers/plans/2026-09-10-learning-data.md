# 学习系统数据基础实施记录

本对话阶段：数据。

范围：只实现 Prompt 1 所需的数据结构、状态管理和浏览器本地持久化。Prompt 2 至 Prompt 9 只用于确定未来需要的数据边界，不实现页面或完整业务流程。

## 已确认规则

- 每日学习时间表示计划学习时长，单位为分钟。
- 学习和复习按“词表 + 单词”分别记录；错题本按单词拼写全局去重。
- 遗留词进入第二天任务时认识次数从 0 开始，旧日记录保留。
- 错题本首次和重新进入阈值均为累计 5 次不认识。
- 移出错题本后保留历史总错误数，重新入库次数从 0 计算。
- 复习阶段位置为第 1、2、4、7、15 天；首次到期为本地次日 00:00。
- 同一天恢复任务集合、固定顺序、当前单词、上一个单词、答题/反馈状态和逐词状态。
