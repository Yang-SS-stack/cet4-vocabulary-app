# 单词学习网页空壳 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一个可在本机浏览器打开的四级单词学习网页空壳，提供侧栏导航与“今日学习”首页。

**Architecture:** 使用 Vite 创建 React 单页应用；`App.jsx` 只负责当前页面状态、应用标题和导航，页面内容先以静态占位信息呈现。CSS 分为全局基础样式与应用布局样式，后续功能会在独立组件中扩展。

**Tech Stack:** React、Vite、Vitest、React Testing Library、CSS

## Global Constraints

- 仅做本地纯前端网页，不连接服务器、账号或数据库。
- 保持电脑端优先，使用暖纸张底色 `#f2f0ec`、藏青 `#0b2244`、金色 `#96762e`。
- 本阶段不加入词库、学习进度、测验或本地存储。
- 先写并运行失败测试，再写界面代码。

### Task 4: 收起导航栏并保持内容居中

**Files:**

- Modify: `src/App.jsx`
- Modify: `src/App.css`

**Interfaces:**

- Produces: 左侧导航栏的展开/收起状态；收起时导航从左侧滑出，内容区改为相对整个页面居中；页面标题切换时淡入淡出。

- [ ] **Step 1: 写失败测试**

Add a test that renders `App`, clicks the button with accessible name `隐藏导航栏`, then expects the main navigation to have `aria-hidden="true"` and the toggle button to have accessible name `显示导航栏`.

Run: `npm test -- src/App.test.jsx`

Expected: FAIL，因为当前页面不存在名为“隐藏导航栏”的控制按钮。

- [ ] **Step 3: 实现收起状态与动画**

Add `isNavOpen` state in `src/App.jsx`. Render one icon-only toggle button with `title` and an accessible name that changes between `隐藏导航栏` and `显示导航栏`. Add an `is-nav-collapsed` class to the application shell when `isNavOpen` is false and set the navigation `aria-hidden` attribute from that state.

In `src/App.css`, keep the existing expanded navigation width. When collapsed, make the navigation column zero width, translate the sidebar to the left, place the toggle at the viewport's left edge, and let the content column fill the viewport. Add a short opacity-and-vertical-offset animation to the page intro keyed by the selected page.

- [ ] **Step 4: 运行测试与构建**

Run: `npm test; npm run build`

Expected: PASS，导航测试与构建均无错误。
