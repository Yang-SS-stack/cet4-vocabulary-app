# 单词学习网页空壳 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建一个可在本机浏览器打开的四级单词学习网页空壳，提供侧栏导航与“今日学习”首页。

**Architecture:** 使用 Vite 创建 React 单页应用；`App.jsx` 只负责当前页面状态、应用标题和导航，页面内容先以静态占位信息呈现。CSS 分为全局基础样式与应用布局样式，后续功能会在独立组件中扩展。

**Tech Stack:** React、Vite、Vitest、React Testing Library、CSS

## Global Constraints

- 仅做本地纯前端网页，不连接服务器、账号或数据库。
- 保持电脑端优先，使用暖纸张底色 `#f2f0ec`、藏青 `#0b2244`、金色 `#96762e`。
- 本阶段不加入词库、学习进度、测验或本地存储。
- 先写并运行失败测试，再写界面代码。

### Task 1: 创建可测试的 React + Vite 项目

**Files:**
- Create: `package.json`
- Create: `vite.config.js`
- Create: `src/main.jsx`
- Create: `src/test/setup.js`
- Modify: `.gitignore`

**Interfaces:**
- Produces: `npm run dev` 启动本地网页；`npm run build` 生成可发布文件；`npm test` 运行单元测试。

- [ ] **Step 1: 用 React 模板生成项目基础文件**

Run: `npm create vite@latest . -- --template react --no-interactive`

Expected: 当前目录出现 `package.json`、`src`、`index.html` 和 `vite.config.js`。

- [ ] **Step 2: 安装依赖与测试工具**

Run: `npm install; npm install -D vitest jsdom @testing-library/react @testing-library/jest-dom`

Expected: 安装完成且 `package-lock.json` 创建成功。

- [ ] **Step 3: 配置 Vitest 浏览器模拟环境**

Update `vite.config.js` to export a Vite configuration with:

```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  test: {
    environment: 'jsdom',
    setupFiles: './src/test/setup.js',
  },
})
```

Create `src/test/setup.js`:

```js
import '@testing-library/jest-dom/vitest'
```

Add the following script to `package.json`:

```json
"test": "vitest run"
```

- [ ] **Step 4: 验证空项目可以构建**

Run: `npm run build`

Expected: PASS，生成 `dist` 目录且无构建错误。

### Task 2: 实现应用外壳与页面切换

**Files:**
- Create: `src/App.test.jsx`
- Modify: `src/App.jsx`
- Modify: `src/App.css`
- Modify: `src/index.css`

**Interfaces:**
- Consumes: React 的 `useState`；Task 1 的测试环境。
- Produces: `App` 组件，含导航项“今日学习”“词表”“模拟练习”“统计”“设置”；点击导航项后展示对应标题。

- [ ] **Step 1: 先写失败测试**

Create `src/App.test.jsx`:

```jsx
import { render, screen } from '@testing-library/react'
import userEvent from '@testing-library/user-event'
import App from './App'

test('clicking vocabulary navigation shows the vocabulary page', async () => {
  const user = userEvent.setup()
  render(<App />)

  await user.click(screen.getByRole('button', { name: '词表' }))

  expect(screen.getByRole('heading', { name: '词表' })).toBeInTheDocument()
})
```

- [ ] **Step 2: 运行测试并确认失败原因正确**

Run: `npm test -- src/App.test.jsx`

Expected: FAIL，因为当前页面没有名为“词表”的导航按钮。

- [ ] **Step 3: 写最小界面实现**

Replace `src/App.jsx` with a component that:

```jsx
const pages = ['今日学习', '词表', '模拟练习', '统计', '设置']
```

Uses `useState('今日学习')` to track the selected page, renders one `button` for each value in `pages`, and renders an `h1` with the selected page name. When the selected page is `今日学习`, render the static text “从今天的单词开始”。

In `src/App.css`, add a two-column desktop layout with a 220px sidebar, paper background, navy text, gold active navigation indicator, and visible keyboard focus styles. In `src/index.css`, set `box-sizing: border-box`, remove default body margin, and set a readable system font stack.

- [ ] **Step 4: 运行测试并确认通过**

Run: `npm test -- src/App.test.jsx`

Expected: PASS，1 个测试通过。

- [ ] **Step 5: 验证生产构建**

Run: `npm run build`

Expected: PASS，构建无警告或错误。
