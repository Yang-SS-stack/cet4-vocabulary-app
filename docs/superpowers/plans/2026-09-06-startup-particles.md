# 启动过渡实施计划

目标：保留文字散开再组成主页 LinguaJet 的一次性动画，粒子错落运动、连续聚合，无鼠标交互；统一暖灰、深蓝、淡金配色。

边界：仅独立分支 codex/startup-particles；主线已审核的词书过渡与固定导航按钮保持不变。新版本先本地预览，不合入 main。

1. App.jsx / App.css：主页预先挂载但隐藏且不可交互，启动页固定覆盖；直接读取真实品牌位置，移除替身目标。所有降级路径都能进入主页。
2. particleMotion.js：有种子的独立随机分布，每颗粒子不同的散开幅度、时长、聚合延迟和路径偏移。测试有限坐标、终点收敛、各阶段连续。
3. ParticleTextTransition.jsx：复用文字采样，限制粒子总数；按独立时序绘制并使用与帧率无关的平滑追随；末尾粒子与真实品牌交叉淡化。取消动画、窗口变化和减少动态效果均安全结束。
4. SplashScreen / GradientWaves：暖纸色背景、深蓝文字，淡金明暗；点击时冻结背景绘制，退出完成释放资源。
5. 验证：更新页面交接测试并先验证失败；执行完整测试、lint、build；桌面与窄屏实际预览检查过渡、布局和可用性。记录观察的局限，不以截图声称精确帧率。

本次在当前对话内按顺序执行，沿用已确认方案。
