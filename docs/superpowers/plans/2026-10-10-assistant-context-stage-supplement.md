## 当前UI准备与P-03-B：本次时间及真实能力状态

- [ ] 四个紧凑入口“学习计划／单词记忆／专属练习／学习答疑”固定在输入框上方并排，对话区域独立滚动；窄屏不遮挡必要操作，不出现额外引导说明。复用现有窗口、动画和输入组件。
- [ ] 首次欢迎使用用户最终需求中的原文；当前模拟及待开放状态明确显示。欢迎文案描述最终能力不等于这些能力已实现。回答“是／否”是对话请求，不要求恢复此前删除的固定回答按钮。
- [ ] 计划缺少本次明确时间时先询问；用户本次明确输入或主动确认的5～60分钟值可复用，不从每日设置推断本次空闲时间。滑块显示初值不代表用户已确认。
- [ ] 配置/建议/微调/确认复用现有AssistantPlan及规则；原首次设置、普通保存/跳过和独立学习不变。真实应用仍留P-03-C，不新增应用权限。
- [ ] 将界面意图与本地规则准备分离；未开放的模型能力可说明或澄清，但不能模拟已成功生成真实记忆方法、解析或练习。

P-03-B正式建议接口继续遵守已批准的数量/时间/摘要白名单。逐词资料、例句、选中文本属于后续对话能力的新发送范围，不能借上下文整合偷偷加入当前供应商请求。P-03-C确认应用及共同调用保护已有详细安排，本次不重复或扩展。

## P-05：四种意图与应用上下文

- [ ] 定义统一内部意图和上下文协议，分别表达计划、单词记忆、练习和答疑。按钮表达意图，内部指令不作为冗长用户消息展示；用户看到简短且对象明确的提问。
- [ ] 优先级保持：当前明确请求→当前明确选中内容→应用当前学习上下文→相关历史。历史只辅助个性化，不能据此猜测当前想问的词或问题；冲突、多个目标或关键信息缺失时自然澄清。
- [ ] 今日学习页通过真实任务当前项读取目标词，复用词条及相关例句；保留来源、词书和请求时对象标识。复习/额外学习是否复用同一上下文需在详细方案确认，不由本补充扩大已确认场景。
- [ ] 推荐在今日学习当前单词页点击“单词记忆”时，以该页当前词作为默认目标；词表多个词且未选中时询问“你想记住哪个单词呢？”。这条为实现推荐，目标确认表现随详细方案核定，不将本批注的技术问答冒充完整规则验收。
- [ ] 答题时所选的干扰项不等于目标词，不复用学习记录中的choice.selectedWord作为助手所问对象。用户明确指向其他词时以明确请求为准。
- [ ] 点击时绑定对象；之后切词不会把迟到回复错贴到新词，也不会隐式重发请求。呈现对象变化和失效，是否允许继续展示旧词解释在详细交互方案明确。
- [ ] 单词记忆没有目标时先问词；练习没有范围时先澄清，可提供今日错题/当前词/指定知识点等已有可用范围；答疑优先现有明确输入或明确传入的选中文本，没有问题时问“你遇到了什么问题呢？”。有信息不重复询问，无信息不猜测。
- [ ] 精确查词仍复用真实词库；需要呈现软件词条时跳转词表定位已有卡片，不在悬浮对话中另造词条页面。
- [ ] 新的上下文发送字段、长度、来源、隐私、取消及工具权限先审核。有限对话与工具调用继承原权限、总调用/费用/时长/步数限制及停止条件。

技术核对：LearningSession已经用当前任务的progress.wordId从已加载词条映射取得item，并读取example。将这些应用数据传给助手即可表达当前页面对象，无需截屏、图像识别或视觉语言模型（VLM）。当前FloatingLearningAssistant只接收selectedPage等参数，尚未连接具体学习对象；后续需要一个小范围、只读的上下文通道，不复制学习状态或建立第二套学习系统。实际字段名由详细方案确定。

## P-05/P-06：单词记忆、答疑与搜索缺项

- [ ] 明确单词记忆输出：实际词义和例句基于词库/核验资料；词根词源仅有依据时陈述；趣味联想、谐音等生成记忆提示与语言事实分开。不将个人记忆故事当作真实词源，不承诺学习效果。
- [ ] 学习答疑使用用户问题和必要材料，已有资料可回答时优先使用；找不到依据时说明缺失，来源不能伪造。教学方法与练习质量沿用P-06已有审核要求。
- [ ] 搜索前先检查是否确有已配置且可调用的受限搜索服务。本次代码核对未发现该能力；不可把Codex本身的联网工具当作LinguaJet产品接口。
- [ ] 必须增加搜索时，单独审核允许的查询/资料范围、来源回传、调用预算、失败与停止、内容不扩大权限等规则；搜索额度与模型调用分别核算，不能默认无限。搜索不可用仍保留词库和原学习功能。

P-06题量、题型、答案校验、解析、作答保存、主观评分、更正与有效结果回流已经有完整任务，不重复新建一套练习系统。四个入口按已验收能力逐项开放，能力尚未实现时说明状态。

## P-07/P-08：界面整合与对应验收增补

- [ ] 对话中切入计划/建议/返回时继续使用已有窗口和动画，底部快捷入口保持可达；启动、首次设置及恢复界面不出现助手。
- [ ] 明确欢迎已显示状态、聊天与上下文保留范围。当前实现只在应用会话内保留，收起重开不重播，未完成文字续显；刷新后是否保存欢迎/聊天另审，不自动新增持久化结构。
- [ ] 验证已明确时间不追问、未明确时间不生成假设计划；计划草稿失败不阻断原学习，确认前不写记录。
- [ ] 验证当前词、明确选中其他词、多个词未选中、缺词条、答题选择干扰项和等待中切词，不发生对象猜测或迟到回复误绑定。
- [ ] 验证练习目标明确/缺失、答疑已有问题/选中文本/无问题，内部指令不泄露为用户长消息、不反复介绍。
- [ ] 验证四按钮固定并排、对话滚动、重复打开、桌面/窄屏/键盘/减少动画及真实能力状态。UI流程、真实模型回答质量、搜索真实来源、练习答案质量分别在对应能力启用后验收，不用模拟回复代替。

前次随机干扰项及朗读间隔仍为原学习流程的独立待处理问题；它们不是四项Agent能力的新增模块，本规划补充不取消这些问题或擅自改动已冻结题目、进度与朗读规则。

## 2026-10-10：本轮任务审核进展

用户确认本次时间流程：点击学习计划或首次回答“是”，如果本次时间尚未明确，先询问“你这次准备学习多少分钟？”。可直接回复明确分钟数，或通过已有5～60分钟滑块选择并确认。时间明确后才进入计划配置/建议；同一助手会话复用已明确时间，修改前不重复询问，不把每日设置当作今天的空闲时间。此项为规则审核通过，尚未实施；上方工程任务不据此勾选完成。

新增UI缺陷待修复：用户在d8c8168折叠导航中反馈“展开导航栏”偶尔点不到或误点统计。代码检查发现展开按钮与统计行可能占据同一高度，展开按钮未设置自身叠放优先级；折叠后的导航文字仅opacity为0，绝对定位到按钮附近，仍可能参与点击命中。属于待验证的覆盖/命中冲突判断，不冒充浏览器实测根因。实施前核验重叠处实际命中，修复后检查展开按钮中心/边缘、折叠/展开动画及相邻统计入口，确保不吞掉合法导航操作。

用户确认未接模型时的入口行为：四按钮可点击；单词记忆有明确当前目标时发送简短且对象明确的请求（如“帮我记住 exhibit”），缺目标则询问哪个词；专属练习先确认明确范围，缺范围则询问；学习答疑接收具体问题，缺问题则询问。对象明确后提示该能力尚未接入模型，不生成假记忆建议、题目或答案。本轮验收意图、上下文和澄清流程，真实回答仍属后续阶段。这是交互审核通过，不是功能已实现或测试已通过。

用户确认聊天保留范围：收起重开保留全部对话及未完成文本，页面内切换保留对话；刷新或关闭网页重开开始新会话，重新显示欢迎语。本轮不新增聊天持久化结构；跨刷新保存及期限/清除方式留正式对话阶段另审。此项为交互审核通过，不是新功能验收。

本轮必要交互审核已收齐，不重新审核已确定视觉和入口。后续实施按下列清单拆分检查，工程完成、独立审查、真实浏览器检查和用户逐步验收分别记录。
