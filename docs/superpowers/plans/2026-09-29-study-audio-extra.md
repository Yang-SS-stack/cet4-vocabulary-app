# 今日学习朗读、过渡与额外学习

> For agentic workers: 使用 superpowers:subagent-driven-development 逐项实施并审查。

**Goal:** 改善今日学习的音频与状态连续性，并允许完成后继续学习新词。

**Architecture:** 保留固定日任务，额外学习独立持久化并复用现有学习规则；统一手动和自动播放的所有权，按学习阶段串行播放；标题与下方内容分层过渡。

**Tech Stack:** React、Vite、Vitest、浏览器 localStorage / Web Locks / Audio / SpeechSynthesis。

用户已确认，实施分支 codex/study-audio-extra，基线 4fa64a7。

## 全局约束
- 保留每日固定任务、历史反馈、旧数据恢复、原有设置及词书浏览；不实施 P-02、Agent 或全局改版。
- 首轮选择在同一页面原地反馈，单词与选项位置不变；答错先红后绿。进入详情固定单词，仅下方内容过渡；只有下一词才整体淡出淡入。保留减少动态效果设置。
- 自动播放：第一轮题面读单词；选错读错误选项单词，再读正确单词；选对读正确单词；第二轮题面读单词与英文例句；第三轮题面仅读单词；详情读单词与英文例句。串行、不重叠，下一词及退出取消，手动重播可用，播放失败可恢复且不阻塞学习。
- 完成今日任务后再次进入先提示是否继续学习更多单词。确认后学习同一本词书默认顺序的未完成新词，不受每日词数上限限制，完成后计入词书总已学习数量且每词只计一次。原任务不扩充或重置；额外过程保存当前词、反馈和详情状态，退出可恢复；全部学完明确提示。
- 所有学习写入继续校验本地日期、任务、单词、版本与答题状态，可靠持久化，多标签冲突不覆盖；无损兼容历史格式。
- 不推送、合并、公开部署或写入 Obsidian。保留主目录未跟踪 P-02 草稿。
