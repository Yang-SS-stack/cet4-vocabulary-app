## 3. 目标、完成条件与边界

用户应能从设置进入一个专用页面，辨认临时连接、执行一个检查、查看必要记录依据，并预览和复制一份不含私密内容的反馈报告。学习页面保持适合日常使用；统计页面呈现已经实现的汇总。

完成条件：

- 三个页面内容归属清楚，不丢现有进度、反馈口径及完整性提示。
- 同标签页切换保留连接；刷新、新标签页仍不继承凭证。
- 打开页面、看记录、切换日期范围不会联网或写学习记录。
- 每次只展示一个当前检查项目的说明、操作和结果；真实摘要与固定非法示例清楚分开。
- 检查结果继续受记录、日期、词书、会话和迟到响应保护。
- 临时检查记录有上限，复制字段经过白名单限制；清空检查记录不会清空学习数据。
- 新增自动检查和必要实际浏览器检查通过；用户完成新增界面验收。

本轮维护操作仅为查看状态、连接/断开、只读检查、看记录依据、复制报告及清空临时检查记录。不加入学习记录修复/编辑/清除、题库编辑、导出导入、模型调用、费用统计、正式管理员登录、后台账号或云端服务。完整统计中的 30 天、趋势图、薄弱词筛选及练习统计仍留在后续阶段。

## 4. 页面、入口及返回方式

### 4.1 设置与独立页面

- 设置页原本机后端检查区替换为一个“开发验收与维护”入口，附一句说明：“查看本机连接、只读检查与记录依据。”不增加主导航常驻项。
- 进入后页面标题为“开发验收与维护”，同一标签页内切换，不打开新站点，不引入第二份学习存储。
- 沿用当前应用内页面切换，不新增网址路由或地址片段。本轮页面不提供可收藏的独立网址；刷新遵循当前应用回到今日学习的行为。
- 页面提供“返回设置”“返回今日学习”按钮。返回设置后把焦点放到入口；回今日学习后放到页面标题或适当入口。
- 主导航中设置作为所属区域：维护页显示时，侧栏设置标记为所属区域，不把它声称为另一个独立主导航页面。页面标题表明实际所在页面。
- 侧栏若采用受控选中状态，只修正本次程序跳转需要的选中同步，保留其他导航行为。

### 4.2 新入口的草稿保护

设置页当前切页会卸载未保存草稿。新入口避免静默丢弃：

- 以现有字段的最新 `draftRef` 与本页草稿基线比较，不用另一标签页的数据自动替换草稿。基线采用本页初始化后的完整草稿（包括显示用默认值），不直接拿它与可能为空的原始设置比较；比较按字段值进行。
- 保存成功后，基线更新为该次实际成功提交的完整草稿；显式重新读取成功后，基线和草稿一起更新为新生成的完整草稿。保存/重读失败保留原基线与未保存修改。因此刚打开、刚保存成功或刚重读成功时进入不误报修改；保存失败后仍保护草稿。
- 没有未保存修改时直接进入；保存中或滚轮尚未稳定时入口暂不可用，等待已有过程完成。
- 有未保存修改时提示：“进入开发验收将放弃本页尚未保存的设置。要继续吗？”默认操作为“留在设置”，另一按钮为“放弃修改并进入”。Escape 等同留下。
- 确认进入只丢弃本页草稿，不自动保存、重新读取、应用建议或修改学习任务。
- 不扩展成全站导航草稿重构；现有设置保存和多标签冲突处理继续保留。

## 5. 三个页面的内容分工

| 页面 | 本轮呈现 |
| --- | --- |
| 今日学习 | 原考试倒计时、词书剩余、学习/复习入口、规则建议与时间估算；今日固定学习、额外学习、复习的必要进度及任务词书差异提示 |
| 统计 | 当前词书累计完成/总量、今日任务概况、到期及任务外积压、今日/近 7 天完成词次、真实反馈、选择作答、更正和有效反馈汇总、覆盖范围与异常提示 |
| 开发验收与维护 | 临时连接、当前检查、固定非法示例、失败与恢复说明、任务/事件/异常的原始对账明细、最近 20 次临时检查、报告预览与复制 |

### 5.1 今日学习

移走完整“计划依据与已记录反馈”面板。学习建议仍读取同一事实模块，不能连同面板移走计算依赖。简要进度仅用现有事实：分配/完成/剩余及额外批次数；任务没有创建时明确显示“尚未创建”。复习已有进度与词书差异提示复用，避免重复显示同一信息。

今日任务的词书按保存的任务标签呈现，当前设置换书不改当日任务。规则建议中的学习方法研究依据继续留在学习建议中；它与逐条学习记录的对账依据不同。

### 5.2 统计：仅迁移已有汇总

用现有 `buildLearningFacts` 的结果组织展示，不新建统计算法，不调用旧的累计认识进度来替代真实反馈。

- 今日/近 7 天汇总按当前词书和任务日期归属，标明日期区间；近 7 天包括今天。
- 固定学习、额外学习、复习分别展示；“完成词次”与当前词书累计唯一单词数分开。
- 认识/模糊/不认识来自真实事件；选择正确/错误/看答案独立；更正及更正后的有效自评独立。
- 默认复习进度 2 仍不生成或表示两次反馈；历史记录可能缺事件的提示保留。
- 到期和任务外积压表示当前负担，不伪装成过去一天的历史快照；历史补齐投影仍标为预计。
- 已知 0 显示 0，未创建、缺资料、旧记录不完整及冲突无法计算按实际状态显示，不能统一填 0。
- 不显示原始任务、事件 JSON；只说明详细对账记录可从设置中的维护页查看。
- 无后端连接也能查看汇总，界面不会自动联网。

## 6. 独立页面的结构及一个项目一次的操作

沿用纸色、深蓝文字、柔和金色、现有字号与焦点样式，采用便于操作的版式。桌面和窄屏都以清楚的顺序呈现，长标识自动换行，按钮在窄屏可纵向排列；不新增装饰动画。

顶部始终显示页面标题、返回按钮、构建版本信息和临时连接状态。这里的“已建立临时连接”不证明服务此刻仍在运行；没有健康轮询，不虚构实时监控。当前摘要结果另显示“尚未检查/检查中/格式检查通过/依据已变化/失败”。

主体分为三个视图，仅一个可见：

1. **连接与检查**：当前检查项目、操作与结果。
2. **记录依据**：浏览器本地任务、事件、异常明细。
3. **检查记录**：最近 20 次操作记录与报告。

切换视图只改变显示。第一次进入，未连接时显示配对项目，已有连接时显示当前学习摘要项目。用户可从一个项目选择器选择“连接本机”“当前学习摘要”“固定非法示例”；每次只展开所选项目的说明、按钮、结果与下一步。

| 项目 | 说明/操作 | 结果表达 |
| --- | --- | --- |
| 连接本机 | 按手册启动服务，输入密码式连接码，主动点击连接；继续使用已有权限提示与健康检查流程 | 已建立临时连接/明确失败；连接成功清空输入；不是账号登录 |
| 当前学习摘要 | 已连接时可手动点击检查，自动取得一致的批准字段 | “连接正常，摘要格式检查通过”；这是格式和关系检查，不是学会证明 |
| 固定非法示例 | 已连接时可手动发送现有固定合成输入；明确不是用户学习记录 | 只有规定错误码与 422 同时成立才显示“错误输入已被拒绝”；其他情况按实际错误提示，无法确认规定的拒绝结果 |

等待时禁止重复连接/检查及检查项目切换，保留“取消当前操作”和“断开连接”。取消只中止等待并使回调失效；检查期间保留已建立的会话，连接期间取消则保持未连接。断开同时取消等待并丢弃当前临时凭证。

取消固定非法示例时，此前仍有效的真实摘要结果可保留，两者分别显示；取消正在进行的真实摘要检查不显示本次通过。非法示例不含真实请求的编号和依据，现有客户端不会把其任何不匹配的 200 当成功；保留这层校验，不新增绕过校验的测试接口。响应异常时只报告“未获得符合约定的拒绝结果”，不声称后端已接受非法数据或补造 200。

离开维护页到其他应用页面，不卸载共享连接管理者；已开始的只读检查可继续结束，返回时能看到结果。记录或日期变更仍立即使其失效。不会因为返回页面而重发检查。

页面没有自动“全部验收通过”按钮。程序检查结果、历史检查结果与用户实际验收三者分开；页面操作记录不自动成为人工通过记录。

## 7. 状态、失败及恢复

| 状态/情况 | 页面行为 |
| --- | --- |
| 未连接 | 显示启动与配对说明，摘要和非法示例按钮不可用；浏览本地依据与统计仍可用 |
| 权限等待/连接中 | 明确提示可能需要 Edge 本地网络许可，不提前判断为拒绝；允许取消 |
| 权限明确被拒绝 | 采用现有明确查询结果及固定提示，指向该站点权限恢复说明 |
| 网络失败/超时 | 说明服务或站点权限可能影响连接；无法区分时不编造具体原因或状态码 |
| 凭证无效/过期/服务重启 | 按现有条件提示重新启动服务并用新码配对，不重复使用已消费连接码 |
| 429 过于频繁 | 显示服务提供且校验过的等待秒数；不自动重试 |
| 学习、设置、日期或有关依据变化 | 清除“当前检查通过”状态，显示需要重新检查；旧成功仅作为发生时的历史记录 |
| 另一标签页写入 | 不自动 `reload` 或接纳新快照；显示记录已变化，按已有显式重载方式恢复，避免绕过草稿冲突保护 |
| 非法/不匹配服务响应 | 固定错误提示，不渲染任意服务文本；旧/取消后的回调不能补写成功 |
| 没有逐次历史/记录冲突 | 原有完整性提示保留，不从默认进度推造历史事件 |
| 浏览器数据损坏/未知版本 | 仍走现有应用级恢复入口；本页面不绕过校验加载损坏记录，也不承诺此时仍可进入维护页 |

取消是用户停止等待，不承诺远端尚未收到请求。当前检查不产生模型费用；以后付费模型的取消语义留给 P-03-B 单独设计。

## 8. 临时记录与可复制报告

### 8.1 最小记录

由现有共享连接管理者维护内存列表，每次用户发起的连接、真实摘要、固定非法示例操作生成至多一条终态记录；连接内多个网络阶段不冒充多次人工检查。等待中只显示当前操作，不增加已完成记录；结束、失败、取消或依据失效时登记一次。迟到回调不得重复追加。

依据变化若发生在请求进行中，将该操作登记为失效终态；若发生在操作已经结束后，只改变历史结果的当前适用标记，不追加第二条操作记录。

- 最近最多 20 条，超过删除最旧条；不保存到 localStorage、sessionStorage、文件、后端或 Obsidian。
- 同标签页切换保留，刷新/关闭后清空；断开连接保留安全历史，但当前检查结论清除。
- 提供“清空临时检查记录”，按钮明确只清检查记录；不改变连接、当前结果或学习存储。操作执行前采用页面内明确确认。
- 记录只表示当时的技术操作。历史成功显示“历史结果”；当前依据变化时不得继续充当当前通过状态。

### 8.2 白名单字段

| 字段 | 来源/规则 |
| --- | --- |
| 临时操作编号 | 标签页内递增编号，区别多次操作；不是账号、学习任务或凭证 |
| 前端版本 | 构建时取得的分支、提交、构建时间及是否含未提交内容；缺少来源显示“未取得”，不声称与正式部署自动比对 |
| 项目类型/样本类型 | 固定枚举：连接、当前真实摘要、固定合成非法示例 |
| 浏览器操作时间 | 开始与结束时间，明确这是本机时间；不声称可信服务端审计时间 |
| 等待耗时 | 使用单调计时计算本次前端等待，包括生成摘要等本地过程；不是模型耗时或纯后端耗时 |
| 技术结果 | 成功、按预期拒绝、失败、取消、依据变化；使用固定枚举和中文映射。未知/异常响应属于失败，不推断后端接受了输入 |
| HTTP 状态 | 仅客户端实际取得并验证的结果；无法取得显示“未取得”，不推测网络失败对应 403/500 |
| 请求编号/服务接收时间 | 仅真实摘要成功且客户端严格核对后的 `requestId` / `receivedAt`；不可用时不补造 |
| 安全错误 | 已批准错误码、固定中文说明、校验后的重试秒数和需重启标志；不读取原始异常全文 |
| 依据状态 | 当前仍匹配/已失效/不适用；固定非法示例不代表真实摘要被检查 |

成功真实摘要的 200 来自客户端已限制为 200 且校验全部返回字段的既有流程。错误状态沿用客户端公开错误中的实际值；响应格式错误如未保留可靠状态，则显示未取得。连接流程可记录总体结果；不添加未观察到的各阶段状态。

前端构建信息只读取得，最多暴露上述指定值；不读取全体环境变量、凭证或磁盘路径。未提交工作区构建标注“含未提交改动”，不能只凭主分支提交号让用户误认为新界面已经上线。构建信息不可取得时仍正常构建和使用。

### 8.3 预览、复制与隐私

- 点击“预览检查报告”后展示将复制的完整固定格式文本；复制只发生在用户主动点击时。
- 报告由白名单重新组装，不能直接序列化客户端状态、内部依据字符串、请求、响应或异常对象。
- 不含连接码、sessionToken、认证请求头、snapshotToken/factsToken、内部 `readBasis`、完整学习快照、考试日期、具体计数、逐词/逐次明细、浏览器完整版本字符串或用户自由输入。
- 可复制选中的单条检查记录；标明是当前结果还是历史结果，并附报告生成时间，防止旧报告被理解为实时状态。
- 复制失败保留可选中的报告文本，提示手动复制；不使用自动上传、发送反馈、导出下载文件或替用户提交问题。
- 当前页面中的详细记录只供浏览器本地查看。报告故意不包含学习明细；需要额外明细时另行沟通，不默认放宽字段。

## 9. 复用结构、数据流与发送范围

通俗说明：原学习存储负责保存学习事实；事实模块负责统一计算；共享连接管理者负责临时连接、请求和失效；三个页面只负责呈现。这次不增加第二套学习算法。

```text
原浏览器学习记录 → 同一只读事实模块
                     ├─ 今日学习：必要进度和既有规则建议
                     ├─ 统计：已有今日/近 7 天汇总
                     └─ 维护：本地对账明细

用户主动连接/检查 → 现有共享连接管理者 → 现有固定本机服务
                            └─ 安全终态记录（标签页内最近 20 次）
                                      └─ 白名单报告 → 用户预览/主动复制
```

请求地址继续固定 `127.0.0.1:5280`，来源继续为原在线网页。保留 GET health、POST session、POST facts/check；不新增接口、任意服务地址或允许来源。本轮不修改后端学习契约、监听范围、配对规则、会话期限、限流、正文大小或等待参数。

真实摘要仍由 `buildFactsRequest` 构造已有白名单：日期/时区/依据标识、现有设置、词书/任务/积压/反馈汇总、规则建议。逐词、逐次事件、任务明细及原始完整快照不发送。维护页的显示、复制与新增临时记录不会扩大摘要发送字段。

凭证继续只在原客户端闭包保存，不能写入新记录或交给复制组件。显示层取得的成功检查信息也经过字段白名单；不把服务响应中的所有字段放到页面公开状态。

拆分现有事实面板为“今日简要进度”“统计汇总”“对账依据”三个展示职责，复用其格式化和分页逻辑。细节以批准后的执行计划为准，避免创建意义相同的重复组件或无关全站重构。

### 10.3 新增人工验收，只给一步

以下是拟验收项目清单，不是现在同时交给用户的操作步骤。实施完成后按当时可检查版本逐项引导：

1. 设置中的新入口与独立页面标题。
