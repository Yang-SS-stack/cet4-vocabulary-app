# 四级词汇学习与真题练习 Web App 设计文档

日期：2026-08-03
状态：已与用户确认，待实施

## 1. 背景与目标

用户是准备大学英语四级考试的大学生，希望拥有一款适合自己的单词学习软件。软件参考「不背单词」「百词斩」等产品的思路，但面向个人使用做精简：以四级真题语境记词为核心，配合间隔复习、词频标注、模拟练习，帮助用户在考试前系统掌握词汇。

目标：

- 电脑优先的 Web App，个人本地使用，双击或本地启动即可运行
- 全部四级词汇与高频四级词汇两种词书可选
- 按实际考试日期自动生成每日学习计划
- 学习卡片标注每个词在四级真题中的出现频率
- 提供四级模拟练习（词汇类题型先行，完整真题套卷后置）
- 后期可评估套壳成手机 App

## 2. 用户与使用场景

- 用户：开发纯小白，不负责编程，只做产品决定
- 场景：以电脑端学习为主，每日固定时间背新词、复习旧词；考前进行专项或综合模拟练习
- 环境：Windows 电脑，已安装 Node.js v24.18.1；浏览器为 Chrome/Edge 一类现代浏览器

## 3. 核心决策

已与用户逐项确认：

1. 形态：Web App，电脑优先，版本稳定后再做手机适配
2. 技术方案：React + Vite 前端项目，纯前端、无后端
3. 核心学习方式：语境认词 + 间隔复习；打字模式作为后期附加模式
4. 学习与模拟两条路径分开：「学习单词」管词汇积累，「模拟练习」管实战检验
5. 视觉风格：参考用户提供的幻灯片质感（纸感、藏青、金色、衬线标题），导航切换带丝滑过渡
6. 首次进入有引导流程（昵称、考试日期、每日词数目标）
7. 单词卡片显示真题出现频率，高频词书取真题词频前 2000

## 4. 功能设计

### 4.1 首次引导

首次打开网页时：

1. 居中弹窗输入昵称
2. 检测到首次使用后，继续询问：
   - 考试还剩多少天（选择考试日期或直接填天数）
   - 每日建议学习单词数：系统按「剩余天数 ÷ 剩余词数」自动计算并展示
   - 每日想学习单词数：用户填写期望值，实际计划以期望值为准
3. 完成后进入「今日学习」，顶部显示：`xxx，距考试还剩 X 天；今日新词 N 个；待复习 M 个`
4. 之后每次打开跳过引导；昵称和所有设置可在「设置」页修改

「是否首次使用」与昵称均存储在浏览器本地。

### 4.2 今日学习

每日学习流程：

1. 主页显示今日概览：剩余天数、今日新词数、待复习数
2. 点击「开始学习」进入新词卡片：单词、音标、英美发音按钮、释义、1–2 条真题例句、词组搭配、真题出现次数与频率等级
3. 每张卡片可听发音，看完后自评「认识 / 模糊 / 不认识」
4. 新词过完后进入当日测验，按设置勾选的题型出题：选择题、英译中、听音选词
5. 答错的词进入错词本，当天测验与后续复习中再次出现，直到答对掌握

复习调度（简化记忆曲线）：新词学完后第 1、2、4、7、15 天各复习一次，到期自动进入今日待复习。

每日计划：`剩余词数 ÷ 剩余天数`，上限 80 个新词/天；修改词书或考试日期后自动重算。

### 4.3 词表浏览

- 按字母顺序或真题频率排序查看当前词书
- 支持搜索单词
- 点击单词查看完整卡片（释义、音标、发音、例句、词组、频率）

### 4.4 模拟练习

进入后先选择：

- 专项练习：听力 / 阅读 / 翻译 / 写作
- 综合练习：混合出题，模拟考试节奏

阶段一（先行实现）：

- 词汇类专项：选择题、英译中、听音选词，从当前词书出题
- 翻译、写作真题：首批整理近 2–3 年公开题目入本地题库，后续扩充
- 可选计时，提交后自动判分，错题自动记录

阶段二（后置实现）：

- 完整四级真题套卷（2021–2025 共 30 套 PDF 为数据来源）
- 听力音频、阅读全文、答案解析

### 4.5 统计

- 单词统计：已学词数、已掌握词数、连续学习天数、每日完成情况
- 练习统计：各专项最近得分、历史成绩趋势、错题回顾入口

### 4.6 设置

1. 昵称修改
2. 词书：全部四级词汇（约 4544 个）/ 高频四级词汇（真题词频前 2000 个）
3. 考试日期：保存后自动重算每日计划
4. 每日目标：显示系统建议值，用户填期望值，实际以期望值为准
5. 练习题型：勾选 选择题 / 英译中 / 听音选词
6. 发音：美音 / 英音
7. 数据：导出备份（JSON 下载）、导入恢复、重置进度
8. 界面：默认浅色纸感主题，深色主题后续版本

## 5. 数据设计

### 5.1 主词库

来源：KyleBing/english-vocabulary 的 CET-4 json-sentence 数据。

- 共 4544 个唯一单词
- 4512 个带例句，4496 个带英美音标，3743 个带词组搭配
- 字段：word、英美音标、释义（含词性）、词组、例句及译文

### 5.2 真题词频

来源一：cduang/word-statistics-cet4，基于 2006–2017 年 12 年 36 套四级真题文本统计，共 5000 个词，含逐词出现次数。

来源二：catteacher0515/cet4-download，收录 2021–2025 年 30 套四级真题 PDF，部分含听力音频。开发阶段用词频统计脚本提取文本，按相同方法统计，与来源一合并。

说明：

- 词频为文档级统计（含题干与选项文本），非官方数据
- 2018–2020 真题文本公开来源较少，暂不纳入，后续可补
- 总次数 = 旧统计 + 新统计；频率等级按次数分档（高频 / 中频 / 低频）
- 主词库 4544 词中约 2285 个能匹配到词频；未匹配词显示「低频 / 真题未收录」

### 5.3 高频词书

取合并后词频前 2000 个词，与主词库做交集；已验证前 2000 全部在主词库内，音标、例句、词组完整。

### 5.4 真题题库

阶段一先内置近 2–3 年翻译、写作真题文本；阶段二加入完整套卷、听力音频与答案解析。

版权边界：真题内容仅用于本地个人学习，不对外发布。

### 5.5 本地存储

- 词库数据以静态 JS 文件随应用分发，不写入浏览器存储
- 用户数据（昵称、设置、学习进度、测验成绩）存浏览器本地：优先 IndexedDB，兼容 localStorage
- 提供 JSON 导出/导入备份

## 6. 视觉与交互

参考用户提供的 AI 工作坊幻灯片设计语言：

- 配色：暖色纸张底 `#f2f0ec`、白色卡片、深藏青主色 `#0b2244`、金色点缀 `#96762e`；辅以青绿、酒红、紫、绿等强调色
- 字体：标题用衬线字体（Georgia / 宋体风格），正文用现代无衬线字体
- 组件：圆角卡片、细边框、浅阴影、chip 标签、顶部进度条、克制的按钮
- 过渡：导航切换采用淡入 + 轻微位移，时长约 0.35–0.45 秒，缓动曲线与幻灯片一致
- 布局：左侧导航栏 + 内容区；电脑优先，最低适配常见笔记本宽度；手机适配后续版本

## 7. 技术架构

- 前端：React + Vite，纯静态构建，无后端
- 运行：本地开发用 Vite dev server；日常使用构建成静态文件，浏览器直接打开
- 数据管道：Node.js 脚本负责词库合并、词频统计、真题文本提取与校验；新真题 PDF 放入固定目录运行脚本即可刷新
- 发音：浏览器 Web Speech API（系统 TTS）为主；后续可评估接入在线发音资源
- 状态管理：React Context + Hooks，用户数据持久化到浏览器本地
- 组件划分：应用外壳与导航、首次引导、今日学习、单词卡片、测验、词表浏览、模拟练习、统计、设置
- 词库数据量约 7–8 MB（原文），构建时做字段裁剪与压缩，控制最终体积

## 8. 测试策略

- 数据脚本输出校验：词条数、字段覆盖率、重复词、词频合并正确性
- 核心逻辑单元测试：每日计划计算、间隔复习调度、测验判分、错词重入
- 手动验收清单：首次引导、每日学习全流程、题型勾选生效、设置修改后计划重算、备份导出导入、导航过渡流畅

## 9. 实施里程碑

1. M1：项目骨架、视觉系统、导航与页面切换过渡
2. M2：数据管道（词库合并 + 词频扩展）、词表浏览
3. M3：今日学习流程（卡片、自评、测验、间隔复习、错词本）
4. M4：首次引导、设置、统计
5. M5：模拟练习阶段一（词汇类题型 + 翻译写作真题）
6. M6：模拟练习阶段二（听力阅读真题）、备份完善、App 套壳评估

## 10. 风险与边界

- 真题版权：仅个人本地学习使用，不对外发布
- 词频统计为文本级统计，可能包含题干/选项中的词，不代表官方考纲权重
- PDF 文本提取可能存在误差，关键题目需人工校验
- 浏览器本地存储有容量上限，数据量大时依赖 IndexedDB；换设备需手动备份导入
- 2018–2020 真题词频缺失，统计覆盖 2006–2017 + 2021–2025
