# CET-4 单词卡片 AnimatedList 设计

## 目标

将词书 `CET-4` 的点击后内容替换为基于 React Bits `AnimatedList` 的单词卡片列表，减弱页面切换的突兀感，同时保留现有纸张风格、单词信息和网格布局。

## 交互与动效

1. 点击 `CET-4` 后，词书选择界面替换为单词列表。
2. `CET-4` 标题在替换期间向上轻微移动并淡出，随后在原位置附近向下轻微移动并淡入。
3. 标题重新可见后，单词卡片依次以轻微缩放和淡入方式进入。
4. 返回词书按钮仍直接返回词书选择界面。
5. 不提供“减少动态效果”专用分支。本次动效是该页面既定体验的一部分。

## 组件边界

- 新增 `AnimatedList` 组件，基于用户提供的 React Bits 源码，依赖 `motion`。
- 组件接收单词数据和渲染函数，将每项作为可动画的卡片容器；不限制词表高度，也不显示滚动渐变层或自定义滚动条。
- `VocabularyPage` 保留词书选择与返回状态，负责将单词数据传入 `AnimatedList` 并提供卡片内容。
- `VocabularyPage.css` 保留卡片的纸张视觉，只增加标题和卡片列表的进入样式。

## 无障碍与范围

- 单词卡片是信息内容，不会被伪装为可点击控件。
- 不注册全局键盘监听，也不拦截 Tab 键，避免影响页面既有导航。
- 不调整数据格式、导航、其他页面或启动动画。

## 验收与测试

- 测试点击词书后显示 `CET-4` 标题、返回按钮和全部单词卡片。
- 测试单词卡片由 `AnimatedList` 渲染，并保留单词、词性、音标、释义和例句。
- 测试点击返回按钮后恢复词书选择界面。
- 运行项目测试、代码检查和生产构建。
