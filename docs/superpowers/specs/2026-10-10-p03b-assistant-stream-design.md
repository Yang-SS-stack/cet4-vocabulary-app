# P-03-B 对话生成与异常卡片补充设计

本文件记录用户本次三项批注及两张异常状态参考图，补充已审核悬浮助手设计，不重新设计产品入口。

## 范围与边界

- main 首次设置的六项、保存、跳过保持原样；原学习、复习、冻结任务、进度与记录独立运行。
- 不接 Qwen，不新增网络模型请求、额度服务、数据库结构或认证修改；不推送、发布、合并或写 Obsidian。
- 草稿仅在内存；采用进入确认，最终应用禁用，真实应用留 P-03-C。
- 真摘要、5～60 分钟、三目标、新词60秒/复习20秒、向上取整5分钟并限于预算和真实数量继续使用现有规则。
- 保留桌面移动/缩放、手机半屏下滑阈值、收起中止、键盘焦点、减少动态效果和旧版回退。

## 对话生成

首次打开才开始等待动画；等待结束后从第一个字符开始展示模拟回答。使用 Unicode 字符或字素完整分段，避免半个 emoji。文字逐步加入真实文本节点，气泡自然增长，不用完整隐藏文本撑开空间。等待与文字生成期间禁止重复请求；按钮重新可用以生成完成为准。

安排计划的回答全部生成后，留短暂阅读停顿，再进入已用真实摘要准备的草稿页；切换前重读依据。不得按固定时间在文字未结束时跳转。所有回答仍明确模拟。

用户追加明确：不是每一次点击学习助手都要重新生成已经生成过的文字，保留之前生成的部分。收起暂停当前等待/生成/跳转并使活动回调失效，保留所有消息、回复文本与生成游标。再次打开时继续同一个本地模拟回答的剩余文字，不能重播前缀、重复首次引导、追加重复消息或重发请求。完整回答已生成但尚未切页时，重新打开可继续阅读停顿及核对最新依据后进入草稿；隐藏期间不得切页。禁用/卸载终止活动计时器，不产生迟到动作。未来真实 provider 的取消/恢复协议另行实现，本轮恢复只读已知本地模拟文本，不进行网络请求。

减少动态效果下保留等待反馈，可一次展示完整回答，并从同一完成路径进入草稿。动态偏好改变及动画不支持不能卡住对话。辅助技术只在回答完整时播报完整内容，不逐字刷屏；键盘焦点留在输入区。

## 发送文字

发送前记录输入框的真实矩形。消息成为唯一用户消息后，以实际气泡矩形为终点，从输入框位置与形状过渡到深蓝气泡，再落入对话。使用浏览器动画能力与现有动效工具，约350毫秒；不复制第二条可读消息，不改变请求业务语义。不能测量、减少动态效果或中途收起时直接落定并清理动画；长文本不溢出窗口。建议提问可使用普通气泡入场，不假装来自输入框。

## 超时与额度耗尽

参考图的真实任务摘要下展示独立暖灰提示卡、柔金时钟/电量图标、醒目标题、设置已保留说明和“使用规则建议”主按钮。标题使用“生成建议超时”和“免费额度耗尽”，卡片内明确“模拟状态 · 未接入模型”，不能表示真实余额或服务异常。失败卡显示时隐藏普通数量建议/采用/确认区域，以免同时显示成功和失败；保留内存设置和草稿，实际原学习入口仍可用。

“使用规则建议”重读真实持久化摘要与现有规则，生成新的内存草稿并回到审核区，不应用计划、不扣任务、不写记录。选择成功/超时/额度耗尽继续通过手动演示控件，切换/重试只影响模拟展示。数据不可读时说明原因，不伪造可用建议。

## 验证与交接

检查逐字中间态、完整后切页、Unicode、首次打开、重复/中止/重开、实际发送几何、减少动态效果、异常卡与规则回退、不写入及原学习独立性。交接明确未来 provider 可替代模拟输出，完成事件与 UI 动画分开，权限与真实应用仍由后续阶段负责。
