让桌面和手机用户更容易切换五个页面，并在进入今日学习后先看到学习与复习入口。采用现有暖纸、深蓝、柔金和字体系统，不替换已审核的统计、词表、滚轮、学习建议及学习会话设计。

开发基线为 main `6ee921c23f45834a53e9ed6c4a7ddd5eb4ef0cdb`；执行前重新核对，保留与本任务无关的文件。实际代码：`src/App.jsx`、`src/App.css`、`src/components/LineSidebar.jsx`、`src/components/LineSidebar.css`、`src/components/TodayLearningPage.jsx`。

用户选择 B，A 的浅金选中块不采用。B 使用线性标记、图标与文字；手机采用抽屉建议，而非把桌面窄栏直接缩成手机导航。

## 3. 桌面导航

- 宽度大于 800 CSS 像素：展开侧栏约 220 像素，收起为约 72 像素图标栏。正文随宽度变化自然获得空间。
- 展开状态显示品牌 LinguaJet、五项导航、顶部收起按钮和现有底部短句；收起状态显示 L、展开按钮和五项图标。
- 五项名称和顺序保持“今日学习、词表、模拟练习、统计、设置”。图标对应日历、词书、练习、统计、设置，使用现有线描风格的语义图标，不新增图标依赖。
- 当前项使用深蓝加粗文字／图标和加长金色线标。其他项为较柔和的深蓝灰及短线；不增加 A 的底色块。
- 收起状态当前图标左侧使用金色标记。悬停或键盘聚焦图标时显示名称；辅助阅读始终保留完整名称。
- 进入开发验收与维护仍指向设置所属位置，保留既有 `aria-current="location"` 语义。模拟练习仍为原占位页面，不新增练习功能。
- 新收起状态仍能操作导航，不能沿用当前“隐藏侧栏即 aria-hidden/inert”的设置。学习／复习专注模式则继续完全隐藏导航。

## 4. 手机与窄屏导航

宽度小于等于 800 像素时，顶部只保留品牌和菜单按钮，不保留横向溢出的五项导航。默认抽屉关闭；手机开关状态与桌面展开状态分别管理。

菜单按钮打开左侧抽屉，宽度为 `min(280px, calc(100vw - 56px))`，剩余区域为半透明遮罩。抽屉盖在当前页面上，不改变正文宽度、文档高度或原滚动位置。短屏抽屉内部可滚动，五项导航与关闭按钮均可到达。

关闭方式：关闭按钮、遮罩、Escape，或选择目的页面。重复点击当前页只关闭抽屉，不重新载入页面。打开时锁定背景滚动，焦点进入抽屉；取消关闭返回菜单按钮，实际换页后焦点进入目的页标题。关闭、跨断点或进入学习会话后释放滚动锁与模态状态。

使用原生模态能力及焦点约束，背景不接受点击和键盘操作。所有触摸目标至少 44×44 像素，考虑顶部／底部安全区。菜单、关闭、图标按钮都有中文名称。

## 5. 动效

| 操作 | 方案 |
| --- | --- |
| 桌面收起／展开 | 约 280ms 缓出；侧栏和正文宽度同步变化，标签在固定行内淡出／淡入，图标连续归位 |
| 导航悬停 | 约 150ms 文字、图标和线标变色；不改变行高 |
| 选择页面 | 约 200ms 金色标记在导航项间移动；现有页级进入动效保留 |
| 手机打开／关闭 | 抽屉约 260ms 侧滑与遮罩透明度同步变化；正文不跟随移动 |
| 选词切换 | 见独立选词规格；与导航无耦合 |

快速反向操作从当前可见状态接续，不先跳回起点；退出中不把焦点交给正在消失的控件。系统减少动态效果时直接落终态，功能和状态完整。无需动画依赖，不用动效阻止普通页面导航。

## 6. 今日学习入口位置

桌面与手机内容顺序统一为：标题／词书 → 今日学习与今日复习按钮 → 考试与词书状态 → 今日任务进度 → 学习建议入口。

两个按钮复用原动作、处理中状态、重复点击保护、日期保护、额外学习确认及返回焦点行为，不增加第二份入口。桌面并排；手机在 320 像素及以上视口内并排，各自至少 48 像素高，字号与内边距适配窄屏。

手机任务环继续原有纵向排列，不为了放进首屏而缩成难读的小环。正常的长页面可以滚动；导航开关和学习建议打开不能额外撑长页面。学习建议仍为独立弹窗，内部滚动。

## 7. 实施验证要求

自动检查导航语义、收起后仍可操作、专注模式隐藏、维护页归属、手机抽屉焦点与关闭、跨断点清理。入口上移验证只有一份学习／复习按钮，动作和重复点击保护不变。

实际浏览器覆盖桌面 1280×720、1440×900；手机 320×568、390×844、横屏 844×390，并在 800／801 断点附近核对。检查无横向溢出、触摸目标、短屏抽屉、滚动位置、快速开关、减少动态效果，以及设置、词表、统计、建议弹窗的导航可用性。

人工验收按交接卡一次只发一个操作，用户回复“1”后再发下一项；不重做已通过的 P-03-A 或整套旧页面人工验收。
