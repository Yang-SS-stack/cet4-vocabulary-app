# 词表浏览第一版

日期：2026-09-07。用户已确认范围并要求在独立工作区实现预览版。

## 范围与行为

- 从 main 的 9e8812a 建立 codex/vocabulary-browser，不合入旧词卡分支。
- 仅词表：英文拼写和中文释义搜索、字母/词频排序、翻转详情、浏览器发音、文档同步。
- 当前词书内按输入内容部分匹配，忽略英文大小写与首尾空格；搜索结果每页最多 21 个，绝不补入无关词条；无结果给出清空搜索入口。
- 普通词书默认 A–Z，高频词书默认词频降序；同频按字母，缺失词频最后。没有词频数据不伪造次数或等级。
- 改搜索/排序回第一页；换书清空搜索、恢复该书默认排序；翻页/筛选后卡片从正面开始。
- 正面为单词、词性、音标、简要释义。背面为现有数据的完整释义、例句/翻译、所有词组、词频与发音；缺失详情明确提示。
- 卡片使用 420ms CSS 3D 翻转；文字面隐藏背向视角，静止后不模糊。减少动态效果偏好下立即切换。
- 正面整面为原生按钮；背面内容点击可返回，并提供明确返回按钮。Enter/Space 可翻转，Escape 可返回；隐藏面不可聚焦且不进入读屏树；返回时焦点回到正面。
- 背面固定可用阅读高度，详情可独立滚动，底部操作保持可见；文本选择、滚动和发音不引发翻转。
- 发音只响应主动点击，使用英语浏览器语音；连续点击中止之前朗读，离开词卡中止朗读。不支持/失败给出可读提示。
- 不含任何学习状态操作、存储或复习算法，也不改今日学习。

## 实现选择

保留 VocabularyPage 管理词书、加载和分页；单独 WordCard 管理翻转和 SpeechButton 管理浏览器发音。搜索与排序在分页前以 useMemo 计算。无需新依赖或重构导航。

相较于把所有逻辑塞入页面，此方案让键盘和语音生命周期可以独立验证；相较于弹窗详情，此方案保留用户明确要求的原位翻转。

## 验收

每个功能先写失败测试再实现；覆盖中英文搜索、空结果、分页重置、排序缺失/同频、翻转焦点、详情缺失、语音支持/失败/取消。运行全量测试、lint、build；浏览器核对桌面/窄屏、长详情、键盘和减少动态效果。README 描述实际功能、数据局限及手动验收，旧分页文档改为 21。
