# P-03-B UI 生成与应用边界补充

2026-10-09。用户在本对话说明 UI 与 Qwen 分工后回复“开始吧”，授权执行本次 UI、接口及交接调整。服务端保护草稿的次数、等待及网络措施仍待 B 单独审核，不因本轮开始实施获批。

## 确定的行为

- 延续 f170841 的初始设置、邀请、5～60分钟和三目标、真实规则及原学习入口；不改已确定设计世界或学习数据。
- “重新计算规则”只同步执行本地计算，无论是否注入模型提供者均不调用它。输入/依据变化仍要求手动操作，不自动重新生成。
- 单独显示“生成 AI 建议”；获得有效模型结果后显示“重新生成 AI 建议”。正式路径没有提供者，入口 disabled，说明尚未接入。配对、额度核查及次数保护由 B 实现，UI 不凭按钮授权。
- 可选 `modelState` 表达 disabled/ready/running/awaiting-quota-check/quota-unavailable/limit-reached/blocked。只有存在提供者且有明确 ready 状态与非空 revision 时允许请求。未知、缺失状态默认禁用。次数和等待只展示服务实际提供的合法数值，不称为免费 Token 余额。
- 每次用户模型操作生成 requestId，当前依据绑定一个不含记录的随机 basisVersion。提供者返回 `{requestId,basisVersion,cacheHit,draft}`，UI 核对二者，并保留原有代次、取消、当前 snapshot/输入检查。二者是响应一致性接口，不是身份或数据真实性证明。
- 模型错误或取消后，本地阻止在发生时已观察到的同一状态 revision 下再次发送；等待期间提前收到的 ready 不算事后恢复。必须由 B 提供者重新取得可用状态并更新 revision。该限制只是 UI 恢复门槛，不能代替服务端持久限额。关闭/改输入不会触发补发，取消不承诺供应商退款。
- 数量、估时、来源、顺序及理由继续经本地检查；模型仅返回经服务端模板整理的理由。模型失败保留本地规则，未知数据不量化，零量不请求模型。
- 建议页只保留一个 disabled 的“采用此计划”，说明将来先进入确认，再应用；当前既不进入真实确认，也不写设置/任务。普通设置保存与按原设置学习保持。

## 实现边界与验证

状态文案用一个纯展示模块维护；SessionAdviceModal 负责用户操作、绑定及迟到结果。没有 HTTP 客户端、真实模型、密钥、后端、代理、额度计数或通用 Agent 框架。B 必须将完整 Facts v1 构建及后端绑定适配在自己的客户端中，不能将 UI 五字段 settings 当完整 Facts。

自动验证：规则操作不触发模型；打开/输入变化不调用；没有提供者或未就绪状态禁用；一次等待只请求一次；零量不请求；请求/依据不匹配拒绝；错误/取消阻断同 revision，更新明确 ready 才可手动重试；缓存标记不冒充新调用；旧记录和冻结任务不变。相关检查后运行2 workers全量回归、lint/build，并在生产预览复核桌面/窄屏；人工验收仍一次一个动作。
