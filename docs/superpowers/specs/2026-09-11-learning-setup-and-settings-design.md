# Prompt 2：首次设置与设置页设计

> 本对话阶段：功能与界面实现（设计确认）。
>
> 范围：只实现 Prompt 2 的首次设置、设置修改页、学习入口概览、推荐信息及相关本地保存。不得实现 Prompt 3 的新词任务、Prompt 4 的复习流程或 Prompt 7 的错题本页面。

## 目标与边界

首次进入“今日学习”时，用户能够完成考试日期、学习词表、每日新词数量和每日学习时长的设置。首次点击“今日复习”时，用户能够单独设置每日复习数量。错题本每日学习数量使用同一套首次设置能力，但暂不新建错题本页面；Prompt 7 的“学习”按钮将在后续接入它。

设置完成后，用户只在“设置”页修改设置；已配置的入口不重复弹窗。所有设置复用 Prompt 1 已完成的浏览器本地学习记录，且不改变现有词表浏览页、词表卡片或后续阶段的学习和复习业务规则。

## 页面与入口

### 今日学习概览

“今日学习”导航页替换现有占位内容，展示：

- 距离考试天数；
- 当前词表的未完成单词数／总单词数；
- “今日学习”和“今日复习”两个按钮；
- 包含研究依据、倒计时计算、系统建议、当前设置和预计时间的学习建议区域。

点击“今日学习”且以下任一设置尚未填写时，打开学习首次设置弹窗：`examDate`、`todayWordBookId`、`dailyNewWords`、`dailyStudyMinutes`。均已填写时，本阶段只说明设置已保存、实际学习流程将在 Prompt 3 启用。

点击“今日复习”且 `dailyReviewWords` 尚未填写时，打开复习首次设置弹窗；填写后，本阶段只说明复习流程将在 Prompt 4 启用。

### 设置页

设置页是所有已完成首次设置后的唯一修改入口，展示并允许修改：

- 考试日期；
- 今日学习词表；
- 每日新词数量；
- 每日复习数量；
- 每日学习时长；
- 发音偏好（默认英音）；
- 错题本每日学习数量。

在 Prompt 7 的错题本页面出现前，错题本首次设置能力不会新增单独页面或导航入口。设置页仍可展示、修改该项，以便用户预先调整。

## 弹窗与滚动选择器

三个首次设置弹窗分别为学习、复习和错题本配置。学习弹窗显示四项必填内容，复习和错题本弹窗只显示其各自的每日数量。每个弹窗显示“保存并继续”和“暂不开始”：前者才保存所有暂存结果，后者关闭弹窗且不改动本地设置；下次从未完成配置的入口进入仍会打开相应弹窗。

所有可选项目使用 iPhone 闹钟风格的滚动选择器：

- 日期：年、月、日三列滚轮合为一个日期选择器；日期范围与每月实际天数一致。
- 词表：现有词书列表的一列滚轮。
- 每日新词、每日复习、错题本每日学习数量：1 至 100，逐个选择。
- 每日学习时长：5 至 240 分钟，每 5 分钟一档。
- 发音偏好：英音、美音两项滚轮。

弹窗默认收起全部滚动选择器，只显示各项当前值。一个弹窗同一时刻仅展开一个选择器；点击另一项时，当前选择器先把当前滚动位置保存到弹窗草稿并收起，再淡出／淡入下一项的选择器。滚轮区域固定约 180 像素高，其余项目保持紧凑单行，避免弹窗因多个展开项而变高。

弹窗与遮罩进入时同步淡入，弹窗轻微向上移动，时长约 240 毫秒；关闭时反向淡出和下移，时长约 180 毫秒。滚动选择器的展开和切换使用同样柔和的短过渡。系统开启“减少动态效果”时，取消非必要动画但保留完整内容与操作。

## 推荐信息与负担提示

研究证据支持间隔学习与主动回忆，但没有能适用于所有成人备考者的统一“每日新词／复习词数”。因此，界面将研究结论、系统估算和用户设置明确分开：

| 信息 | 显示与算法 | 性质 |
| --- | --- | --- |
| 研究建议：新词 | “研究未给出通用固定数量” | 研究结论的边界 |
| 研究建议：复习 | “优先完成全部到期词” | 研究结论的应用原则 |
| 考试计划计算 | 当前词表未完成数 ÷ 距离考试天数，向上取整 | 可复算的计划值 |
| 系统最终建议 | 采用考试计划计算值 | 系统建议，不自动写入设置 |
| 用户当前设置 | 已保存或弹窗草稿中的数值 | 用户决定 |
| 预计每日学习时间 | 新词数 × 3 分钟 + 复习词数 × 1 分钟 | 透明的产品估算，不是研究结论 |

初次没有到期复习词时，复习建议会说明“尚无到期复习；开始复习后按当天到期词更新”。Prompt 4 接入真实复习任务后，建议区域再使用到期词数量，但本阶段不创建任务或排程。

当预计时间高于用户选择的每日学习时长时，保存前显示温和提示，例如：“预计约 45 分钟，超过你的 30 分钟计划。要调整吗？”用户可以返回调整或保留当前设置。系统绝不未经同意更改设置。

“查看依据”展示来源链接和简短说明：间隔学习与主动回忆是学习方法证据，不是固定每日词数的研究处方。

## 数据流与组件边界

学习界面通过 Prompt 1 的 `createLearningStore()` 读取快照、订阅成功保存后的变化，并仅通过 `updateSettings` 修改设置。界面草稿在弹窗内部维护，保存时再一次性提交有效字段；保存失败时保留草稿并显示错误，避免悄悄丢失用户选择。

建议拆分为以下独立模块：

- 学习数据 React 连接层：订阅学习记录，提供设置快照与更新操作。
- 今日学习概览：读取考试、词表与进度信息，控制学习／复习入口。
- 首次设置弹窗：根据 `learning`、`review`、`mistakes` 模式选择字段并处理暂存、保存、负担提示。
- 通用滚动选择器：管理单一展开项、滚轮定位、键盘操作和减少动态效果。
- 设置页：复用选择器编辑全部设置。
- 推荐计算模块：集中计算倒计时、词表进度、建议值、预计时长和负担状态，便于自动化测试。

当前词表的总数从现有词书资源读取；已完成数从学习记录按词表分别统计。同一单词在不同词表的状态继续隔离。现有词表浏览组件和词卡不导入学习界面状态，也不被修改。

## 可访问性与响应式

- 所有按钮、选择器和弹窗支持键盘焦点、明确标签和可见焦点样式。
- 打开弹窗后焦点位于弹窗内；关闭后回到触发按钮。
- 手机宽度下，弹窗改为单列、限制最大高度并可在内容区滚动；180 像素滚轮高度不变。
- 错误、负担提示和保存状态使用可被辅助技术读取的状态提示。

## 验收与自动化检查

新增测试至少覆盖：

1. 三类首次设置弹窗只在相应字段未配置时出现；取消不写入设置，保存与刷新后不再重复出现。
2. 任何弹窗同一时刻只展开一个选择器；切换后前一项的草稿值保留。
3. 日期、词表、数量、时长和发音都使用正确的滚动选项范围和保存值。
4. 倒计时、词表进度、考试计划计算、系统建议、预计时长和负担提示的计算正确。
5. 系统建议不会自动覆盖用户设置；用户可在负担提示后保留原值。
6. 写入失败时保留草稿并显示可理解的错误信息。
7. 弹窗进入、退出、选择器切换和“减少动态效果”行为正确。
8. 设置页修改成功后，学习记录仍保持；现有词表页面与词表卡片回归测试通过。

## 研究依据与限制

- Cepeda 等人的综述与定量综合支持分散练习对延迟回忆的价值，但不提供可直接套用到成人英语备考的统一每日词数。[Distributed practice in verbal recall tasks](https://pubmed.ncbi.nlm.nih.gov/16719566/)
- Karpicke 与 Roediger 的外语词汇实验发现，重复提取比已掌握后的重复学习更能改善延迟回忆。[The critical importance of retrieval for learning](https://doi.org/10.1126/science.1152408)
- Kornmeier 等人的词汇实验在其受试者和材料中发现，间隔 4 至 12 小时的条件在后续保持上优于很短间隔；该结果不能外推为所有用户的每日词数处方。[Spacing learning units affects both learning and forgetting](https://pubmed.ncbi.nlm.nih.gov/35303977/)

因此，产品只将这些研究用于解释“间隔学习＋主动回忆”的原则；每日词数与预计时间均清楚标为可调整的产品计划或估算。
