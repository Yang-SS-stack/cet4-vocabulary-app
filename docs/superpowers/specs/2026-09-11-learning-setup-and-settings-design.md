# Prompt 2：首次设置与设置页设计

> 本对话阶段：功能与界面实现（2026-09-13 首次设置流程修订）。
>
> 范围：只实现 Prompt 2 的首次设置、设置修改页、学习入口概览、推荐信息及相关本地保存。不得实现 Prompt 3 的新词任务、Prompt 4 的复习流程或 Prompt 7 的错题本页面。

## 目标与边界

用户第一次进入网站并完成欢迎动画后，系统立即打开一个合并的首次设置弹窗。用户在同一弹窗中完成考试日期、学习词表、每日新词数量、每日复习数量和每日学习时长的设置，不再等到点击“今日学习”或“今日复习”时分别打开弹窗。错题本每日学习数量暂不纳入这个弹窗，也不新建错题本页面；Prompt 7 的“学习”按钮将在后续接入错题本设置流程。

设置完成后，用户只在“设置”页修改设置，欢迎动画结束后不再重复弹窗。用户选择“暂不开始”或使用 Escape 关闭时不保存；下次重新进入网站并完成欢迎动画后仍会显示首次设置弹窗。所有设置复用 Prompt 1 已完成的浏览器本地学习记录，且不改变现有词表浏览页、词表卡片或后续阶段的学习和复习业务规则。

## 页面与入口

### 今日学习概览

“今日学习”导航页替换现有占位内容，展示：

- 距离考试天数；
- 当前词表的未完成单词数／总单词数；
- “今日学习”和“今日复习”两个按钮；
- 包含研究依据、倒计时计算、系统建议、当前设置和预计时间的学习建议区域。

首次设置改由应用入口统一处理。“今日学习”和“今日复习”按钮不再负责打开首次设置弹窗；首次设置完成后，本阶段分别说明实际学习流程将在 Prompt 3 和 Prompt 4 启用。

### 设置页

设置页是所有已完成首次设置后的唯一修改入口，展示并允许修改：

- 考试日期；
- 今日学习词表；
- 每日新词数量；
- 每日复习数量；
- 每日学习时长；
- 发音偏好（默认英音）；
- 错题本每日学习数量。

在 Prompt 7 的错题本页面出现前，错题本首次设置能力不会新增单独页面或导航入口。设置页仍可展示、修改该项，以便用户预先调整。

## 弹窗与滚动选择器

首次进入网站只显示一个合并弹窗，其中包含考试日期、学习词表、每日新词数量、每日复习数量和每日学习时长。弹窗显示“保存并继续”和“暂不开始”：前者才一次性保存全部暂存结果，后者关闭弹窗且不改动本地设置；下次重新进入网站时仍会再次显示。错题本首次设置模式保留给 Prompt 7 接入，但本阶段没有可见入口。

所有可选项目使用 iPhone 闹钟风格的滚动选择器：

- 日期：年、月、日三列滚轮合为一个日期选择器；日期范围与每月实际天数一致。
- 词表：现有词书列表的一列滚轮。
- 每日新词、每日复习、错题本每日学习数量：1 至 100，逐个选择。
- 每日学习时长：5 至 240 分钟，每 5 分钟一档。
- 发音偏好：英音、美音两项滚轮。

弹窗默认收起全部滚动选择器，只显示各项当前值。一个弹窗同一时刻仅展开一个选择器；点击另一项时，当前选择器先把当前滚动位置保存到弹窗草稿并收起，再淡出／淡入下一项的选择器。滚轮区域固定约 180 像素高，其余项目保持紧凑单行，避免弹窗因多个展开项而变高。

弹窗与遮罩进入时同步淡入，弹窗轻微向上移动，时长约 240 毫秒；关闭时反向淡出和下移，时长约 180 毫秒。滚动选择器的展开和切换使用同样柔和的短过渡。系统开启“减少动态效果”时，取消非必要动画但保留完整内容与操作。

## 推荐信息与负担提示

产品建议必须给出可执行的每日新词数量，同时避免把固定数字包装成适用于所有人的研究结论。因此，界面以用户的词表进度和考试日期生成个性化建议，并将学习方法依据、计划计算和用户设置明确分开：

| 信息 | 显示与算法 | 性质 |
| --- | --- | --- |
| 学习方法建议 | “使用间隔学习与主动回忆；复习时优先完成全部到期词” | 研究结论的产品化应用，不给出固定数量 |
| 考试目标需要 | 当前词表未完成数 ÷ 距离考试天数，向上取整 | 可复算的个性化计划值 |
| 系统建议 | 采用考试目标需要值；首次弹窗与设置页变更考试日期或词表时自动写入当前草稿，最高可选 100 个 | 可继续手动修改的个性化建议 |
| 用户当前设置 | 已保存或弹窗草稿中的数值 | 用户决定 |
| 预计每日学习时间 | 新词数 × 60 秒 + 复习词数 × 20 秒，再向上取整至 5 分钟 | 透明的产品估算，不是研究结论 |
| 计划结果 | 比较考试目标需要与用户当前设置，说明可按期完成，或预计落后并给出调整方向 | 对设置结果的即时反馈 |

初次没有到期复习词时，复习建议会说明“尚无到期复习；开始复习后按当天到期词更新”。首次设置草稿中的每日复习数量默认使用现有产品默认值 20，用户可在弹窗中直接调整。Prompt 4 接入真实复习任务后，建议区域再使用到期词数量，但本阶段不创建任务或排程。

弹窗和设置页共用以下实时联动规则：

1. 每日新词建议值为“当前词表未完成单词数 ÷ 距离考试天数”，向上取整后限制在 1 至 100。
2. 修改考试日期或学习词表时，立即重新计算每日新词和每日学习时长，并把结果显示在对应滚轮摘要中。
3. 修改每日新词或每日复习数量时，立即重新计算每日学习时长。
4. 用户可以在自动计算后单独修改每日学习时长；若随后再次修改考试日期、学习词表、新词数量或复习数量，系统再次按公式更新学习时长。
5. 计算出的新词数量超过 100 时显示 100，并提示“按当前日期和剩余词量，考试前可能无法完成，请调整考试日期或学习计划”。
6. 考试日期为今天或过去时不允许保存，并提示选择未来日期。

弹窗在每日学习时长附近直接解释：“预计时间按每个新词约 1 分钟、每个复习词约 20 秒计算，结果向上取整到 5 分钟；你仍可自行调整。”该说明必须保持可见，不依赖展开帮助内容。
例如每日新词 13 个、每日复习 20 个时，原始估算为 19 分 40 秒，滚轮自动显示 20 分钟。

当公式计算出的预计时间高于用户手动选择的每日学习时长时，保存前显示温和提示，例如：“按当前数量预计约 25 分钟，超过你的 20 分钟计划。要调整吗？”用户可以返回调整或保留当前设置。系统绝不在保存后静默改写用户选择；自动联动只发生在当前可见草稿中。

“查看依据”展示来源链接和简短说明：间隔学习与主动回忆是学习方法证据；界面中的每日新词数字来自当前词表、学习进度和考试日期，不是固定的研究处方。

## 数据流与组件边界

学习界面通过 Prompt 1 的 `createLearningStore()` 读取快照、订阅成功保存后的变化，并仅通过 `updateSettings` 修改设置。界面草稿在弹窗内部维护，保存时再一次性提交有效字段；保存失败时保留草稿并显示错误，避免悄悄丢失用户选择。

建议拆分为以下独立模块：

- 学习数据 React 连接层：订阅学习记录，提供设置快照与更新操作。
- 今日学习概览：读取考试、词表与进度信息，控制学习／复习入口，但不再控制首次设置弹窗。
- 应用入口：欢迎动画结束后检查五项首次设置是否完整，并控制合并弹窗只在未完成时出现。
- 首次设置弹窗：显示五项合并设置，处理实时联动、暂存、保存、日期错误和负担提示；`mistakes` 模式仅保留给 Prompt 7。
- 通用滚动选择器：管理单一展开项、滚轮定位、键盘操作和减少动态效果。
- 设置页：复用选择器编辑全部设置。
- 推荐计算模块：集中计算倒计时、词表进度、1 分钟／20 秒预计时长、5 分钟向上取整、建议值和负担状态，供弹窗、设置页与今日概览共同使用。

当前词表的总数从现有词书资源读取；已完成数从学习记录按词表分别统计。同一单词在不同词表的状态继续隔离。现有词表浏览组件和词卡不导入学习界面状态，也不被修改。

## 可访问性与响应式

- 所有按钮、选择器和弹窗支持键盘焦点、明确标签和可见焦点样式。
- 打开弹窗后焦点位于弹窗内；关闭后回到触发按钮。
- 手机宽度下，弹窗改为单列、限制最大高度并可在内容区滚动；180 像素滚轮高度不变。
- 错误、负担提示和保存状态使用可被辅助技术读取的状态提示。

## 验收与自动化检查

新增测试至少覆盖：

1. 欢迎动画结束后，五项首次设置中任一项未配置时自动显示合并弹窗；取消不写入设置，下次进入仍显示，保存并刷新后不再出现。
2. 任何弹窗同一时刻只展开一个选择器；切换后前一项的草稿值保留。
3. 日期、词表、数量、时长和发音都使用正确的滚动选项范围和保存值。
4. 修改考试日期或词表会重新计算每日新词和时长；修改新词或复习数量会重新计算时长；结果按 1 分钟／20 秒公式向上取整至 5 分钟。
5. 新词建议超过 100 时限制为 100 并显示无法按期完成提示；今天或过去的考试日期不能保存。
6. 用户手动修改时长后可保留该值；再次修改其上游数量时会按明确规则重新计算。用户可在负担提示后保留低于预计时间的时长。
7. 写入失败时保留草稿并显示可理解的错误信息。
8. 弹窗进入、退出、选择器切换和“减少动态效果”行为正确。
9. 设置页修改成功后，今日概览立即使用同一公式更新，学习记录仍保持；现有词表页面与词表卡片回归测试通过。

## 研究依据与限制

- Cepeda 等人的综述与定量综合支持分散练习对延迟回忆的价值，但不提供可直接套用到成人英语备考的统一每日词数。[Distributed practice in verbal recall tasks](https://pubmed.ncbi.nlm.nih.gov/16719566/)
- Karpicke 与 Roediger 的外语词汇实验发现，重复提取比已掌握后的重复学习更能改善延迟回忆。[The critical importance of retrieval for learning](https://doi.org/10.1126/science.1152408)
- Kornmeier 等人的词汇实验在其受试者和材料中发现，间隔 4 至 12 小时的条件在后续保持上优于很短间隔；该结果不能外推为所有用户的每日词数处方。[Spacing learning units affects both learning and forgetting](https://pubmed.ncbi.nlm.nih.gov/35303977/)

因此，产品只将这些研究用于解释“间隔学习＋主动回忆”的原则；每日词数与预计时间均清楚标为可调整的产品计划或估算。
