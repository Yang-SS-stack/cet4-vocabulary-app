# LinguaJet 品牌启动页与词书导航设计

日期：2026-08-09
状态：已完成，等待用户验收

## 目标

将四级单词学习网页统一为“捷语 · LinguaJet”品牌，增加需要用户主动点击后才进入的欢迎启动页，并把词表从单层单词列表升级为“词书列表 -> 词卡列表”的可扩展结构。

## 已确认体验

- 产品完整名称为“捷语 · LinguaJet”；正式学习页面左上角仅显示“LinguaJet”。
- 每次重新打开网页时显示启动页，使用暖纸色背景，不增加单独的开始按钮或自动跳转。
- 启动页先以带闪烁光标的打字效果显示“欢迎来到LinguaJet！很高兴见到你！”，完整显示后停留 1 秒，再从末尾逐字删除，最后用同一光标打出“让我们来进行一些不一样的语言学习体验吧！”。
- 第二句完整显示后，再显示闪烁的“点击任意处继续”。
- 启动页使用低亮度、低速度的蓝色波浪背景；该背景只用于启动页，不进入日常学习页面。
- 用户点击启动页任意位置后，启动页文字逐渐淡出，再进入“今日学习”。
- 页面切换保留现有动态效果：导航点击后的变色与向右伸展、导航收起与恢复、页面淡入和轻微上移；`FadeContent` 负责页面内容切换的淡入承接。
- 电脑端左侧导航在内容滚动时保持可见；手机端改为顶部横向导航并固定在顶部。
- 点击“词表”先显示词书入口；点击“CET-4”显示现有四级单词卡片；提供返回词书列表的按钮；以后可加入其他词书。
- 遵守系统减少动态效果设置；动画关闭时内容和操作仍然可用。

## 技术边界

- 使用 `gsap` 控制 `TextType`、启动页淡出和 `FadeContent` 的时序与清理；使用 `ogl` 绘制波浪背景。
- 新增 `src/components/TextType.jsx/.css` 与 `GradientWaves.jsx/.css`，不把动画逻辑堆进 `App.jsx`。
- 保留现有词表数据与页面风格；不在本次加入搜索、认识/不认识、本地进度或上线功能。

## 验收标准

1. 首次打开和刷新网页都先显示 LinguaJet 欢迎启动页；第一句打出、停留、删除后才打出第二句，光标全程跟随文字末尾并闪烁；文字显示完成后，只有点击任意页面位置才进入今日学习。
2. 点击导航切换页面时，页面内容淡入；现有导航和收起动画仍可见。
3. 内容较长并滚动时，桌面侧栏和移动顶部导航仍可操作。
4. 词表入口先显示 `CET-4`，点击后显示现有单词卡片，返回后重新显示词书入口。
5. 测试、规范检查、生产打包和桌面/移动端浏览器检查通过。
