# 侧栏、设置滚轮与首次弹窗修订验收

设计及浏览器核验：2026-10-06。收尾：2026-10-07。用户以「就这样，开始吧」批准实施。制作分支为 `codex/sidebar-random-selection`，修订基线为 `c548f80`；提交以该分支 HEAD 及维护页构建信息为准。人工体验验收待进行。

## 实现

- 桌面导航收起按钮位于侧栏右边缘、视口垂直中点，展开与收起位置一致，点击区 44×44px。手机顶部菜单与覆盖抽屉沿用原实现。
- 新词选取成为学习目标第四项，在发音偏好之后；使用同一个 SettingsWheel 胶囊滚轮及展开、停靠、关闭动效。选择进入草稿，点击保存设置后生效。
- 首次设置为六项紧凑行：考试日期、学习词表、新词选取、每日新词、每日复习、每日学习时长。选词模式沿原保存通路一起提交；保存失败保留草稿，取消不写入。
- 弹窗标题、内部滚动内容与页脚分开；展开滚轮时面板和页脚位置稳定。短屏滚动内容区，操作按钮始终可见。
- 删除字段下方常态估算说明，保留原副标题、日期警告、超量确认和错误反馈。全局颜色变量、遮罩和原有控件效果保持；生成图不作为取色来源。

## 浏览器证据

使用 Edge 154 隔离 Agent Window 与独立 4176 端口样本，没有修改用户 4175 预览的学习记录。截图在 2026-10-06 拍摄，2026-10-07 归档。

- 1011×668 桌面首次弹窗可见六项及操作按钮；闭合行高 56px，日期值统一字号。
- 390×844 弹窗面板可见高与内容高均为 718px；闭合行高 64px、值为 16px。展开选词行高 164px，页脚顶部始终为约 636.8px，底部约 761.2px。
- 320×568 内容区高 272px、内容高 385px，可内部滚动；页脚底部约 535.2px，小于视口高 568px。文档宽 320px，没有横向溢出。
- 上下滚动在顺序与随机间切换。保存首次弹窗后，v7 全局设置包含随机模式及其余五项；设置页再改成顺序时，持久化值仍为随机，点击保存后正常显示保存反馈。
- 桌面 1440×900 四个学习目标槽位均为 164px。按钮中心在展开时为 (220,450)，收起时为 (72,450)。390 手机设置四项归属学习目标，文档宽与视口同为 390px。

本轮实现核验共 11 次成功的本地确定性按钮选择，目标名称唯一；Jev 未实际调用，成功 0、失败 0、回退 0。键盘、滚动、尺寸模拟与只读检查不计为按钮选择。恢复会话时浏览器守护进程已退出，导航请求未执行；恢复守护进程后会话列表为空，未重复已确认动作。

边界：使用浏览器设备模拟，未在实体手机或 Safari 核验。减少动态效果由代码与自动回归覆盖，未切换操作系统设置；动画未逐帧测量，实际手感仍需人工确认。修订未改选词算法、数据迁移或 Python 契约，原制作版的对应验证保留在[上一轮记录](sidebar-random-selection-acceptance.md)。
