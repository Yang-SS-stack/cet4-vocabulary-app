## 实现结果

- 桌面侧栏展开 220px、收起 72px，收起后五项图标仍可操作，有完整可访问名称；单个金色指示条跟随当前入口。
- 800 CSS 像素及以下使用顶部菜单与模态侧滑抽屉，覆盖页面、内部滚动。关闭、Escape、遮罩及换页均释放滚动锁，取消关闭返回菜单焦点，换页聚焦目的页标题。
- 今日学习／复习动作上移至进度上方，手机并排、至少 48px 高；保留原启动、重复点击及日期保护。
- 顺序／随机偏好位于设置顶部，先修改草稿，点击保存后生效。已创建任务继续使用持久化的词集。
- 随机从当前词书全部剩余候选中无放回抽取；额外批次继承今日任务设置。先加载对应详情，再在写锁中提交同一组 ID；快照变化或候选冲突不会静默替换词集。
- 数据升级到 v7。严格验证旧 v1–v6 后，为全局、每日任务及额外批次补入顺序默认值。摘要请求仍发送原七字段，校验值覆盖完整新状态，Python 契约不变。

## 浏览器核验

使用 Edge 154 的隔离 Agent Window 与独立 `127.0.0.1:4175` 样本，未读写正式预览的学习记录。检查 1280×720、1440×900、320×568、390×844、844×390，以及 800／801 的断点边界。

- 检查尺寸均无横向溢出。390 宽打开抽屉前后文档高度均为 1420px；滚动到约 350px 后开关抽屉，位置保持。
- 原生 dialog 为模态，Tab 保持在抽屉内；Escape 后焦点回到菜单；进入设置后聚焦标题。离开手机断点后抽屉卸载，body 滚动恢复。
- 800×390 的抽屉内部高度 390px、内容高度 459px，可内部滚动。
- 手机学习入口在 390 宽为约 171×48px，在 320 宽为约 136×48px；320 宽的选词模式按钮约 141×48px。
- 实际创建 51 个不重复随机词后刷新，持久化的全部 ID、当前 ID 和模式完全一致，首词仍为 `horrible`。
- 最后一次布局检查确认手机品牌可见；桌面设置原两栏顶部对齐，新增模式区域不挤入原两栏。

浏览器操作共 20 次明确按钮选择，全部采用唯一可见名称直接操作；Jev 调用成功 0 次、失败 0 次、回退 0 次。键盘、滚动、视口切换及只读状态检查不计入按钮选择次数。执行与代码审查均在当前对话内完成，没有独立审查智能体。

边界：上述为浏览器设备模拟，未在实体手机或 Safari 验证。减少动态效果由 CSS 与测试覆盖，未切换真实系统设置；快速反向动画未进行逐帧测量，仍需人工体验。源码实现已完成，这些体验项目不应描述为实体设备验收通过。
