# 今日学习体验与额外学习验收

实施范围及规则见 [实施计划](superpowers/plans/2026-09-29-study-audio-extra.md)。此文记录待核验的真实交互；自动化测试不能替代设备上的音质、播放权限和视觉验收。

## 人工检查顺序

1. 在预览地址打开今日学习。第一轮自动读单词；选择错误释义后原地先红色显示错误选项，再绿色显示正确选项，并依次读两个英文单词。标题与选项位置不应跳动。
2. 点击「继续」进入完整详情。单词标题保持原位，仅下方内容过渡；自动先读单词，再读英文例句。下一词按钮在卡片底部，长内容可在卡片内滚动。
3. 点击「下一词」。只有更换单词才整卡淡出淡入；旧声音停止。第二轮仅显示单词和未翻译的英文例句，自动读二者；第三轮题面仅显示单词并读单词。
4. 分别在题面、选项反馈、完整详情退出，再进入或刷新。应恢复原词、进度和状态，不重复计数。手动重播应停止当前自动播放，不出现重叠声音。
5. 完成当天任务并返回主界面，再点击「今日学习」。取消继续提示后保持概览；确认后进入同词书未完成新词。可以继续超过每日设置数量，完成的单词各计入总已学习数一次。
6. 额外学习退出后重进应恢复；完成一组后自动接续未完成词，原今日任务不变。全部词完成时明确提示。修改词书或每日数量不改写已经创建的当天过程。
7. 在手机尺寸及低高度窗口检查返回按钮、单词、选项与下一词；启用系统减少动态效果后仍能完成相同流程。
