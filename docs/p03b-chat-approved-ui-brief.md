# Chat 已审核 UI：初始学习流程与助手建议需求

来源：用户于 2026-10-09 在当前对话粘贴的最终实施说明，来自 ChatGPT“制作学习建议演示”。**本文整理用户的最终要求，替代此前本地 UI 布局提案；本轮仅做交接，未开始产品实施。** 同日用户已确认：UI 对话先实现界面、规则建议和跳过路径，真实计划应用留给 P-03-C。按[双对话交接](p03b-two-chat-handoff.md)执行此阶段边界。

## 1. 目标与完整流程

在现有 LinguaJet 中升级，不创建孤立 Demo，不重写稳定学习系统。新初始学习界面替代现有初始弹窗，同时完整保留其真实功能：

**打开学习 → 初始学习设置 → 询问是否查看助手建议 → 查看并调整建议 → 确认计划 → 进入现有学习界面。**

助手可选；跳过后继续原学习流程。初始设置、建议预览、任务启动三者要有清楚边界；浏览／修改草稿不能偷偷创建任务或增加学习进度。

## 2. 实施前必须核对

- 旧初始弹窗的全部设置、默认值、联动、校验、保存／失败及持久化。
- 新词量、复习量、词书、当前进度和剩余任务的真实来源。
- 当前任务生成／进入学习调用链，已经冻结的任务与新计划的关系。
- 实际已有 AI 服务及配置。本轮代码核对无 Qwen 接口，只有本机事实接口，不假定已接模型。
- 受影响组件和依赖，新设计必须容纳旧必要功能；有冲突优先保证真实业务正确。

## 3. 新初始学习界面

视觉：暖灰纸色、海军蓝、柔和金色、圆角卡片、清晰数字、轻量动效，兼顾桌面和手机。

内容：真实今日剩余新词／待复习量；原有必要配置；本次可用时间滑块 **5～60 分钟**；“保持备考进度／优先复习／减少负担”三个目标；“完成设置”按钮。

不得把演示值24／20放进正式业务。本次时间与原每日学习时间是不同含义，不用滑块上限60静默截短用户原每日设置。新本次时间／目标的保存方式由实现范围明确，不为展示新增学习数据结构。

## 4. 助手邀请

标题：“要看看助手的学习建议吗？”

说明：“根据你的时间和学习目标，帮你合理安排今天的新词与复习。”

两个入口：“查看助手学习建议”进入建议；“暂不需要，直接开始学习”走项目原学习入口。助手、后端和模型不可成为正常学习的强制依赖。

## 5. 建议、微调和依据

展示新词数量、复习数量、预计用时、时间分配进度条、推荐顺序；提供“查看依据／采用此计划／微调计划／重新生成”。

估时与边界：新词每词60秒，复习每词20秒，合计向上取整到5分钟，取整后不超可用时间；数量不超真实可用量。时间不足、零量、任务全部完成正常处理，未知不冒充零。

三个目标有实际不同的安排：保持备考进度兼顾新词和复习；优先复习先处理待复习；减少负担主动降低数量，不强制填满时间。“查看依据”解释数量选择及估时，不能只换目标文字而返回同一安排。

没有 Qwen 时先提供**明确标注“规则推荐”**的本地方案，保留接入接口。真实产品读取真实摘要计算，不伪装模型结果；模拟数据只在检查／预览场景中使用。

## 6. 异常与继续学习

成功展示完整建议；超时友好提示和手动重试，保留输入；免费额度耗尽提示并允许跳过助手正常学习。UI 阶段模拟失败须标为演示；Qwen 阶段按真实错误和额度核查展示，不假定已经读取余额。

任何 AI 失败都保留规则或原学习入口，不自动重试、充值或切模型。

## 7. 确认与任务应用的最终目标

完整目标是：“采用此计划”进入最终确认，展示任务与时间安排；用户确认后才调用现有任务创建／启动逻辑。

查看建议不改真实学习记录；微调不保存进度；最终确认前不创建或消耗建议任务；不重复扣减词量；不破坏复习调度、历史、冻结任务和同日恢复。

这部分涉及原规划 P-03-C 的真实应用，用户已专门确认留到 P-03-C。当前 UI 可展示草稿微调及预留确认布局，但采用／最终应用操作不能生效，需清楚标明尚未开放；用户跳过建议后仍可按原设置正常开始。无论来源是规则还是 Qwen，本轮不能应用建议计划。

## 8. 工程、回退与验收

复用既有框架、状态管理、组件和规范，UI 与业务分离。保留旧弹窗实现和明确回退方式，不直接删掉。回退不得靠重置数据、强行覆盖设置或清空学习记录。

不改无关配置、认证、数据库及用户记录，不加不必要重依赖。规则估时、目标策略及关键交互要有有效行为验证；检查桌面、手机、返回、重复进入、保存失败、故障与迟到返回。

完整目标的验收项：初始设置完整；时间／目标→邀请；查看／解释／微调／重生成；跳过正常学习；确认建议后进入现有学习；AI故障可继续；无非预期数据变更；旧版可回退。未属于当前阶段的实际计划应用不能标“已完成”。

每个实现对话完成后给检查／构建结果、修改清单、打开新版的路径、真实接入／规则／演示／未完成的区分、遗留问题和回退方式。普通实施步骤自主完成，人工验收仍一次一个操作，重大数据删除／结构改变／不可逆操作先问用户。本轮交接不授权这些破坏性操作或发布。
