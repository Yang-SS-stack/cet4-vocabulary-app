2026-10-03：本轮实际 Edge 在线与人工验收已完成。用户已确认合并和上传，代码已合入 main、上传远端并由 main 正式发布至原 GitHub Pages 地址。验收期间的启动脚本编码和停止提示已最小修复；合并复查仅补一行旧音频测试的异步等待，不改变实际页面。最终证据见 [验收记录](p03a-acceptance.md)，概念与后续安排见 [学习交接](p03a-learning-handoff.md)。

## 首次准备

本机后端是运行在自己电脑上的 Python 程序，用来检查页面发来的摘要格式。前端是浏览器里的学习页面。GitHub Pages 只发布前端，不会替你运行 Python。

先确认电脑已安装 Python；本轮验证版本为 3.13.14。在项目根目录打开 PowerShell，按顺序执行以下三步。第一步创建项目专用环境，第二步安装已经锁定版本的依赖，第三步检查这些依赖能否一起使用。仅首次准备需要安装；不要把项目依赖装到全局环境。

```powershell
py -3 -m venv backend/.venv
backend/.venv/Scripts/python.exe -m pip install -r backend/requirements.lock
backend/.venv/Scripts/python.exe -m pip check
```

如有失败，保留不含连接码的错误信息交给维护者检查，不自行升级依赖或跳过保护。更详细的运行说明见 [后端说明](../backend/README.md)。

## 日后启动与停止

每次使用本机检查，在项目根目录执行：

```powershell
powershell -NoProfile -File scripts/start-local.ps1
```

保持这个窗口打开。它是正在工作的服务进程，关闭页面不等于关闭服务。窗口会显示一次性连接码，请仅粘贴到自己的页面，不截图、保存到笔记或发送给别人。停止时在这个运行窗口按 Ctrl+C；当前启动器正常中断时显示“本机服务已停止。”。实际用户已确认修复后无大段报错，并核对停止后 5280 没有监听；提示原文另有自动信号探针证据，完整范围见验收记录。

服务固定只监听 `http://127.0.0.1:5280`，也就是本电脑。若端口被占用，启动会退出；确认占用原因后再处理，不更换端口、不结束不认识的进程、不开放公网或隧道。启动脚本不自动安装依赖。

## 页面连接和摘要检查

本轮已获单独授权并在原 `https://yang-ss-stack.github.io/cet4-vocabulary-app/` 发布制作版前端。进入设置，展开默认关闭的“开发验收：本机后端”，粘贴码，再点击“连接本机后端”。Edge 可能询问是否允许本站访问本地网络；允许只解决浏览器权限，服务仍会分别检查来源和连接凭证。本轮权限恢复后连接成功，未出现权限弹窗，不能要求每次连接都必须出现弹窗。

配对成功会清空输入框，并提示“已连接；尚未检查当前学习摘要。”然后点击“检查当前学习摘要”，页面会自动从当前记录生成并发送允许的摘要，不需要手工整理文件或导入导出。配对本身不立即上传学习摘要。任务原文、逐次反馈、具体错题及折叠明细留在浏览器；检查只读，不调整计划、不生成任务、不修改历史。

合法摘要预期显示“连接正常，摘要格式检查通过”以及检查时间。点击“检查非法示例”会发送固定测试数据，预期显示被拒绝的结果（422）；其结果单独保留，不替代合法摘要结果。两项是页面临时结果，不是持久化日志。后端校验格式和计数关系，不能证明真实学习发生过。

连接码从启动起 5 分钟有效，成功使用一次后失效；每次启动只允许一次成功配对。独立会话凭证仅在页面内存，12 小时到期且不因使用延长。刷新、断开、会话到期或服务重启后，需停止并重新启动服务，用新码配对。应用内部切换页面可保留同一会话。

点击后的权限查询和健康检查合计最多 60 秒；随后配对另有 5 秒，普通摘要请求最多 5 秒。取消、数据变动、跨日、换书或到期量变化会使旧检查失效，迟到结果不能继续显示为当前成功。需要时手动重新检查，不会无限自动重试。

## 常见结果和处理

| 页面结果或现象 | 处理 |
| --- | --- |
| 明确拒绝本地网络权限 | 从地址栏的站点信息进入本站设置，查看相关权限。实际 Edge 154.0.4258.48 的回环连接测试对应“设备上的应用”；恢复此前“询问（默认）”后重新启动服务、用新码连接成功。“本地网络”与“设备上的应用”是本轮界面的两个独立条目，不修改全局安全策略 |
| 连接失败、超时 | 检查运行窗口、固定地址与站点权限；此消息本身不能证明一定是权限拒绝 |
| 连接码错误、过期、已用或无法确定是否消费 | 停止服务再启动，使用新码；不要反复猜码 |
| 会话失效 | 旧凭证会清除，重新启动并配对 |
| 422 | 固定非法示例被拒绝属于预期；当前合法摘要若被拒绝，交维护者检查，不关闭校验 |
| 429、等待秒数 | 等待显示的秒数后手动重试；每服务每分钟 10 次配对，每会话每分钟 30 次检查，适用失败也计数 |
| 来源不允许（403） | 仅接受批准的 GitHub 来源与跨站请求；不放宽来源来绕过错误 |
| 当前依据已变化 | 学习、反馈、更正、换书或日期变化后重新检查当前摘要 |

所有接口不缓存响应，错误不回显输入。摘要正文上限 256 KiB，配对上限 4 KiB。日常无需理解这些数字，只需知道大请求也不会绕过校验。

## 记录在哪里

学习数据仍属于原浏览器站点存储，后端没有学习数据库。停止后端后，原手动学习、复习、音频和浏览器内事实查看仍可继续。浏览器不同来源各有自己的记录，本机开发预览不会自动取得在线站点记录。不要清理原站点数据；本项没有迁移、导入导出、模型密钥或管理员操作。
