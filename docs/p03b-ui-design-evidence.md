## 桌面与手机结构

初始设置复用 `LearningSetupModal` 的保存、超量确认、失败提示与滚轮；初始六字段由 `INITIAL_SETUP_FIELDS` 给出，顺序是考试日期、学习词表、新词选取、每日新词、每日复习、每日学习时长。

桌面设置框源码宽 `min(100%,860px)`，高 `min(690px,calc(100dvh - 48px))`，内边距 `28px 32px 20px`。主体为两等分可收缩列，间距 `28px`：左列是真实可安排量、本次 5–60 分钟滑块与三个目标；右列是六项每日设置。头部和底部动作不随主体滚动；底部保留“暂不开始”和“完成设置”。截图可见两列结构与独立底部动作。

设置行采用既有滚轮的紧凑弹窗变体，关闭为 `56px` 行，打开为 `164px`；`560px` 以下关闭行是 `64px`。选项高 `48px`，打开表面是原浅白胶囊与浅金选中带；这与设置页原来的固定 `254px` 卡位角色不同，不将紧凑行推广到设置页。

`620px` 以下设置主体改为单列，依次展示剩余量、时间与目标、六项每日设置。框高按 `calc(100dvh - 24px)` 声明，实际还受继承的 `max-height` 约束；`560px` 以下外遮罩内边距和最大高切换为 `12px` / `calc(100dvh - 24px)`，底部动作竖排，完成按钮满宽。390px 截图只展示到考试日期，其余设置在主体内部滚动区，不能将首屏未显示误记为字段缺失。

邀请使用同一原生 dialog 框架，源码宽 `min(560px,calc(100vw - 48px))`。标题、功能性线描对话图标与解释文字引出两个纵向动作：查看建议、跳过并直接开始。390px 截图中标题自然换为两行，没有另设手机视觉系统。

建议框桌面源码宽 `min(760px,calc(100vw - 48px))`，最大高 `calc(100dvh - 48px)`；头、主体、底部动作组成弹性框架，主体 `overflow:auto`。手机源码宽/最大高切至视口减 `24px`，主体水平内边距 `20px`，底部考虑安全区。原生 dialog 的实际宽度仍受浏览器默认最大宽度影响；此记录没有采集计算样式，不把声明宽度当作精确截图测量值。

建议主体先是时间/目标，再是暖纸草稿面。新词、复习、预计用时三列保留在手机，单位在手机独占下一行；下面是深蓝/金色分配条、包含留白的文字图例、学习顺序与依据/微调/重生成动作。底部“按原设置开始学习”和“返回”固定可见。应用区明确说明尚未开放，两个应用按钮禁用；微调只改内存草稿，没有把建议当成已应用计划。
