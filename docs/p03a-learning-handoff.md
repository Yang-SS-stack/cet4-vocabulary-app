# P-03-A 学习交接卡

2026-10-02：实现和本轮自动验证完成，真实在线验收尚未完成。先读 [操作手册](p03a-local-foundation.md)，证据与发布门槛见 [验收记录](p03a-acceptance.md)。

## 三个位置，各做什么

| 位置 | 大白话说明 | 当前用途 |
| --- | --- | --- |
| 代码仓库及 main 分支 | 保存程序源文件的版本柜；main 是指定的一条版本线 | 代码放在那里不代表已经启动，也不代表新版本已经发布 |
| 本电脑 Python 进程 | 打开后持续工作的本机检查员 | 只接收批准的摘要并检查格式；关闭后临时连接状态消失 |
| GitHub Pages 页面 | 把前端文件送到浏览器的网页发布处 | 显示学习界面；不会在云端运行本机后端 |
| 浏览器站点存储 | 当前站点在这台浏览器里的记录本 | 学习历史仍在这里，本项没有后端数据库 |

前端负责从原记录计算摘要，后端检查摘要字段和关系。摘要是“累计完成多少、今日反馈多少、当前设置和状态”的压缩说明；逐条任务、事件和错题没有跟着发送。你点击“检查当前学习摘要”后，生成和发送自动完成；配对成功仅建立连接，不立即发送学习摘要。日常使用无需把记录导出再导入后端。

## 为什么要分开看事实、反馈和检查结果

今日固定任务可能仍属于书 A，当前选择已经是书 B；卡片会分别标明。近 7 天指今天及前 6 个本地日历日，反馈按任务日期归属，复习完成使用词次。真实自评、选择答题、更正分别计算；原反馈和更正后的有效反馈也分别显示。老记录可能有完成词而没有反馈事件，不能伪造历史。

“0”表示有依据且数量为零；“无法计算”表示依据缺失或冲突，不能拿零代替。完整性始终标为不可证明（`not-provable`）：浏览器数据和摘要可以对账，但不能凭这些就证明现实中确实学会了。

## 一个容易验收的小练习

发布并完成连接后，一次只做一件事：

1. 点击“检查当前学习摘要”。预期页面显示格式通过和检查时间。用折叠事实明细核对当前词书、固定任务书和今天的数量。
2. 点击“检查非法示例”。预期固定非法数据被拒绝（422），此前合法结果仍单独可见。
3. 按 Ctrl+C 停止后端，再继续原手动学习。预期检查连接会失败，但学习记录不被后端修改，原学习功能仍可使用。

验收看页面结果和原学习记录，不需要读运行日志、复制请求正文或暴露连接码。上面是待执行的练习，不是已经通过的真实用户验收。若结果不同，记录不含秘密的页面现象交给维护者，不修改保护来追求“通过”。

## 与后续模型、RAG 和数据库的关系

本项只建立受限连接和格式检查，没有调用 AI 模型。P-03-B 才单独设计模型接入。将来若考虑 RAG（检索增强生成，即先找相关资料，再交模型参考），仍需另外明确资料来源、范围和验证方式；本项没有建立检索库或承诺其设计。后端数据库也没有建立。

先做合法/非法分开验收，是为了让未来模型调用接收到边界明确、格式合规的输入。格式通过依然不能保证事实真实、模型建议正确或学习成效，因此以后仍要保留对账和产品验收。
